## 4. 仍然存在的 must_keep 问题

严格子串匹配 8 条缺失，语义核对后：

| must_keep | 页面实际说法 | 判定 |
|---|---|---|
| 根号非负 | “根号”“非负”分别出现 | 别名，内容在 |
| 唯一交点 | “只交一次” | 同义，内容在 |
| 一一对应 | “每个 y 只对应一个 x” | 同义，内容在 |
| 解出变量 | “解出 x” | 同义，内容在 |
| 函数复合 | “复合” | 同义，内容在 |
| 图像变换 | “平移” | 同义，内容在 |
| 对称性 | “关于 y 轴/原点对称” | 同义，内容在 |
| **反函数的反函数** | **全篇 0 次** | **真实缺失** |

结论：must_keep 契约“短关键词”方向对，但**严格子串审计会误报 7/8**；真正要补的是 1.2.3 的“反函数的反函数”。这需要语义/别名匹配 + 定点补讲，而不是压页数。

## 6. 验证 2.3 建议

2.3 只做 must_keep 的“语义/别名 + 定点补讲”，不压页数：

1. **别名匹配**：must_keep 按 2–4 字关键词拆分，允许同义/上下位（如“唯一交点”≈“只交一次”；“解出变量”≈“解出 x”）；或让 LLM 判“页面是否讲了该概念”，只对判否的做补讲。
2. **定点补讲**：只对真实缺失（如 1.2.3 反函数的反函数）修改该节一页的 bullet/audio，不重跑整讲、不增页。
3. **保留页数不强制**：`over_budget` 仍然只是 warning；`content_ok` 不包含页数。
4. **审计输出**：区分 `must_keep_aliases` / `must_keep_real_missing`，避免把 7 条同义表达算成失败。
