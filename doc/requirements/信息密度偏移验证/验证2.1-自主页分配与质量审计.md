# 验证 2.1：LLM 自主页分配 + 页级质量审计

- 日期：2026-11-11
- 数据：同验证 1/2（book `ak5ywpl4x5q4`，series `g91nwrt7el`，lecture 1）
- 变量：讲纲阶段新增“节页分配”LLM 调用；页数只分到 leaf（父节 0–1 页导语）；生成页必须声明 `section`/`page_role`；生成后做 `quality` 审计（丢节/凑页/占位/冒充/超预算/讲内重复）。
- 产物：`验证2.1/slides.json`、`series.json`、`briefs.json`、`stitch.json`、`lecture.json`、`metrics.json`

## 0. 一句话结论

**自主页分配解决了“每节最多 1 页”的误伤，也把 1.1.1/1.1.2/1.1.3/1.2.4/1.3 平移/1.6 有理全部找回来了；但审计只是软告警，没有强制修复，所以出现“计划 19 页、实际 24 页”和“1.5 用 1.3 平移内容冒充”。** 2.1 证明“有预算的自主 + 可机检契约”方向可行，下一步 2.2 要把审计变成阻断/页级修复，并修 must_keep 契约。

## 1. 设计

### 1.1 节树：页数只给 leaf

`attachSectionPlan` 从书签树取子标题，识别 parent/leaf：

- 父节：1.1、1.2；不单独占页（需要导语时 0–1 页）。
- leaf：1.1.1–1.1.4、1.2.1–1.2.3、1.3、1.4、1.5、1.6，共 11 个。
- 1.2.4 是正文子节（书签只到 1.2.3），作为 1.2.3 的 `must_keep`。

这样避免“父节 1 页 + 子节各 1 页”的重复占页。

### 1.2 讲纲阶段：LLM 自主分页

新增 [prompts/plan-sections-v1.md](../../../prompts/plan-sections-v1.md)，同一“讲纲阶段”多一次 LLM 调用：

- 输入：本书名/本讲/章 gist/11 个 leaf（title,parent,page）/预算（target=19，min=17，max=22）。
- 输出：每个 leaf `pages`（1–5）+ `must_keep`（1–5 条）+ `reason`；`total_pages=1+Σpages`。
- 校验：leaf 不增不删不重复；pages 1–5；总页数在预算内；must_keep 非空。
- 失败/无模型：退化为 1 页/节 + 按页跨度补足。

实际输出：**19 页，`section_source=model`**：

| 节 | 页数 | must_keep（摘要） |
|---|---|---|
| 1.1.1 区间表示法 | 1 | 闭区间/开区间/半开区间/无界区间 |
| 1.1.2 求定义域 | 2 | 分母/偶次根号/对数真数/多项式/分段函数 |
| 1.1.3 利用图像求值域 | 1 | 向 y 轴投影/值域与定义域区别/最高最低点 |
| 1.1.4 垂线检验 | 1 | 垂线检验/一个 x 一个 y/圆 |
| 1.2.1 水平线检验 | 1 | 水平线检验/反函数存在条件/一一对应 |
| 1.2.2 求反函数 | 2 | 交换 x/y、解出 y、f⁻¹、定义域值域互换 |
| 1.2.3 限制定义域 | 1 | 限制定义域/反函数的反函数/开平方取正根 |
| 1.3 函数的复合 | 2 | 复合 f(g(x))/顺序不可交换/定义域/平移 |
| 1.4 奇偶 | 2 | 偶/奇/关于 y 轴/关于原点/x² 与 x³ |

### 1.3 生成页级契约

`lib/slides.js` 增加字段并校验：

```json
{"section":"1.1.2 求定义域","page_role":"example","sections":[]}
```

- `content_text/quote` 必须给 `section`（本批必须覆盖/承接小节）；
- `page_role` ∈ `concept|example|formula|graph|bridge|summary`；
- `summary` 只能最后一页；`bridge` 必须列 `sections[]`；
- `section` 必须在本讲 leaf 清单中。

生成 prompt 同时给：全讲节清单（带页数/must_keep）、本批必须覆盖、承接小节、已覆盖小节、页级字段要求。

### 1.4 讲后审计

`auditSections` 写进 `lecture.json.quality` / `slides.json.quality`：

- 丢节：leaf 无页；
- 丢子概念：must_keep 未出现；
- 占位：`待续/后续再讲/本批回顾/下节预告/略过`；
- 冒充：`section` 不在 leaf、`source_anchor.page` 不在节页范围；
- 超预算：实际页数 > 计划 +2；
- 讲内重复：页间 shingle 重叠 >0.5；
- summary/bridge 位置。

### 2.2 审计结果（v1）

- `missing_sections: []`：11 个 leaf 全部有页。
- `placeholders: []`、`summary_pages: []`、`bridge_pages: []`、`duplicate_pairs: 0`：没有占位/回顾/重复。
- `missing_must_keep: 16`：多数是 must_keep 写法问题，不是内容缺失：
  - `奇函数 f(-x)=-f(-x)` 是 allocator 笔误（应为 `-f(x)`）；
  - `多项式定义域为全体实数`、`分段函数定义域` 不在本章原文，属于 allocator 发挥；
  - `偶次根号下非负` vs 生成页“负数不能取平方根等偶次根”，严格子串匹配误报；
  - `多项式与二次函数（抛物线）` vs 页面“二次函数 p(x)=ax²+bx+c 的图像是抛物线”，语义在但字面不同。
- `impersonations: 7`：其中 3 条是共享页边界的**审计误报**（1.1.2/1.1.3 用 `next.page-1` 切范围；书签页可共享）。真实问题：
  - **1.5 的 slide 18/19 用 1.3 的平移内容**（source p33，1.5 页范围 36–37），属于“冒充/复用”；
  - 1.2.2/1.2.3 有 2 页使用 1.2 导语 p29，属于跨节边缘内容。
- `page_count`：19 计划 → 24 实际，`over_budget=true`，`quality.ok=false`。
- 但 `stitch` 仍为 `verified`，ρ=7.5；**旧指标看不到这些问题**，新审计第一次把它们显式化。

## 3. 判定

| 问题 | 判定 |
|---|---|
| LLM 自主分页是否可行？ | **可行。** 19 页分配里 1.1.2/1.2.2/1.3/1.6 等多页分配合理，覆盖明显优于固定 1 页/节。 |
| 是否解决“每节最多 1 页”的误伤？ | **是。** 1.1.2 2 页、1.2.2 计划 2 页、1.3 2 页、1.6 3 页；内容多的节拿到更多页。 |
| 是否解决凑页/冒充？ | **只抓到，未拦住。** 审计发现 1.5 复用 1.3、页数 +5；但只是软告警，没有页级修复/删页。 |
| must_keep 是否可用？ | **方向对，契约不够。** allocator 写长句/公式/笔误/章节外概念；需要“短关键词 + 原文校验 + 宽松匹配”。 |
| 旧指标是否足够？ | **不够。** stitch verified、ρ=7.5，但 page_count/impersonation/must_keep 都不在旧指标里。 |

## 4. 验证 2.2 建议

2.2 不再改“自主分配”的方向，只加“执行与修复”：

1. **把 quality 变成阻断**：`quality.ok=false` 时，按问题类型做页级修复：
   - 超预算：删最低价值页（重复/无新 must_keep/回顾），或重写该节到计划页数；
   - 冒充：要求该页改回本 section 的 source_quote/source_pages，或删页；
   - 缺 must_keep：页级补讲，不重跑整讲。
2. **页数执行**：每批输出后先校验“本批页数 = 本批 section pages 之和 + 首批封面”，不等就修复；`lecture.pages` 保留计划值，另存 `actual_pages`，防止下一次预算被实际页数覆盖。
3. **must_keep 契约**：allocator 输出短关键词（≤8 字，不写公式/句子），并用本章原文/该书 briefs 校验；不合法就重问；生成后用“关键词包含”而非严格子串匹配。
4. **冒充范围**：用 `section` 标题在正文中的字符偏移切 section 文本，而不是只用书签页范围；共享页/跨页用文本偏移判断。
5. **审计 v2**：把 1.5 复用 1.3 这类真实冒充与共享页误报分开；报告里保留 `impersonations` 的 `reason` 和 `source_page/range`。
