## 0. 一句话结论

**2.3 把“严格 must_keep 失败”收敛成“语义真实缺失”：8 条严格缺失中 7 条是别名/同义表达，只有 1.2.3 的“反函数的反函数”真的没讲；定点补讲只改第 10 页一条 bullet，页数仍是 23，`content_ok` 从 false 变 true，`over_budget` 仍 true 但没有压页。**

## 1. 审计变化

`auditSections` 现在同时输出：

- `missing_must_keep`：严格子串缺失（透明保留）；
- `must_keep_aliases`：同义/别名已覆盖；
- `must_keep_real_missing`：真正没讲；
- `content_ok` 只看 `must_keep_real_missing`，**不看页数**。

已知别名规则（本轮）：

| must_keep | 允许的页面说法 |
|---|---|
| 根号非负 | 同时出现“根号”“非负” |
| 唯一交点 | “只交一次/至多一次/唯一交点/至多相交一次” |
| 一一对应 | “一一对应/只对应一个/唯一输出/最多交一次/对应正负两个” |
| 解出变量 | “解出 x/解出 y/解出变量” |
| 函数复合 | “复合” |
| 图像变换 | “变换/平移” |
| 对称性 | “对称” |

`反函数的反函数` 故意不加别名：它必须逐字出现，否则算真实缺失。

## 6. 局限与 2.4 建议

1. **别名表是策展的**：本轮 7 条规则是为这本书的 must_keep 写的。产品化应改成：
   - 关键词/同义词库，或
   - LLM 逐条判“该页是否讲了这个概念”，只对判否的补讲。
2. **补讲句是原文句**：`“话说, 反函数的反函数就是原始函数.”` 能过契约，但口语开头可清理；产品化应让模型把补讲句融进该页口播/要点，而不是直接贴原文。
3. **页数仍超**：23 vs 19 保留，符合本轮要求；如果以后要控成本，可以单独做“页数预算”而非内容质量门。
4. **软冒充 2 条**：1.2.2/1.2.3 用 p29 导语，distance=1，保留；如果要求更严，可改 `section` 或 source_quote。
