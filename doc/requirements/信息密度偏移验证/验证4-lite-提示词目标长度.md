## 3. 解释

### 3.1 成功：口播/引文/内容量

- 口播目标从 40–220 改为 160–220 后，平均从 95 升到 191，且没有短页；模型确实按目标写了。
- quote 从 80 起，全部达标。
- 每页内容 323 字，利用率 72.1%，不再是 2.3b 的“薄页”。
- `stitch ρ` 从 9.56 降到 3.93，进入健康区；`content_ok` 仍 true，没有硬冒充/占位/重复。

### 3.2 失败：要点长度

- 模型把要点写成短句/关键词（如“垂线检验”“区间表示法”），很多 <25 字。
- 12/18 个 content_text 页触发 `bullet_short_pages`，所以 `density_ok=false`。
- 这不是结构/页数问题，是**要点粒度**问题；如果要补，应做 4-lite-b：只改要点 prompt/校验（4–5 条、每条 25–40），不动口播/页数。

### 3.3 指标矛盾

- 整章净字 ρ=2.31，低于文档的健康下限 2.5，看起来“偏松/过度讲解”；
- stitch ρ=3.93，在健康区。
- 两者口径仍未统一；从内容看没有重复/占位，暂不判定为注水，但 `ρ<2.5` 说明 4-lite 可能把口播写长了。

## 4. 判定

| 问题 | 判定 |
|---|---|
| 4-lite 是否提升每页信息量？ | **是。** 平均 167→323，利用率 39→72.1%，口播 95→191。 |
| 是否达成所有目标？ | **否。** 要点长度只有部分页达标，`density_ok=false`。 |
| 是否影响内容正确/覆盖？ | 没有：`content_ok=true`，真实 must_keep 0，12 leaf 全覆盖，硬冒充/占位/重复 0。 |
| 页数是否被强制？ | 没有；24 页保留，计划 19/22 只做对照。 |
| 是否值得继续 4-lite-b？ | **只在你在意要点长度时做**；只改要点，不动口播/页数。否则 4-lite 已经达到“密度翻倍”的主要目的。 |

## 5. 建议

- 如果目标是“每页别太薄”：**4-lite 已达成**，可以收口；要点短是风格问题，不是信息丢失。
- 如果目标是“要点也必须 25–40 字”：做一次 **4-lite-b**，只改要点 prompt + `bullet_short_pages` 软校验；不重跑结构/页数，不改口播目标。
- 无论是否做 4-lite-b，建议修 `planned_pages` 与 `actual_pages` 分离：4-lite 的“计划 22”其实是 2.3b 的实际页数，原始计划是 19；否则每轮预算都会被上一轮实际值覆盖。
