# 验证 2：讲纲节级清单 + 页预算

- 日期：2026-11-11
- 数据：同验证 1（book `ak5ywpl4x5q4`，series `g91nwrt7el`，lecture 1）
- 变量：在讲纲 lectures 上加 `sections[]`（书签 13 节，每节 1 页），页数改为 `max(字数/2000, 节数+1)`；生成 prompt 注入全讲节清单、本批必须覆盖、承接小节、已覆盖小节；批检查点绑定 sections。
- 产物：`验证2/attempt1/`（初版，prompt 把全局清单当成本批必覆盖）；`验证2/attempt2/`（收敛版，明确只写本批/承接、禁止待续页）；`验证2/metrics.json`

## 0. 一句话结论

**节级清单有效，但单独使用会产生 Goodhart 效应。** 它把验证 1 丢掉的 1.1.1 区间、1.1.2 求定义域、1.1.3 图像法、1.6 有理函数全部找了回来，ρ 从 8.71 降到 3.81（进入健康区）；但模型为了“每节都出现”，把页数从 11 推到 18/23，出现“本批回顾”页、占位页、把 1.2 的镜面反射内容冒充 1.5 线性函数的填充页；1.2.4 反函数的反函数、1.3 平移仍然丢。**下一步必须是“每节最多 1 页 + 页数上限 + 禁止回顾/占位页 + 子概念必保留 + 讲内重复检查”，而不是继续加“至少 1 页”。**

## 2. 怎么跑的

与验证 1 相同：3080 仍缓存旧 host 模块，使用同一数据根的临时 3090 跑，跑完关闭。

**关键进步**：验证 1 丢掉的 1.1.1、1.1.2 求法、1.1.3、1.6 有理全部回来了；1.4/1.5 也从“被挤掉”变成有页。13 个书签节在 attempt2 全部出现；1.2.4 反函数的反函数是正文子节（书签只到 1.2.3），1.3 平移是节内子点，二者属于“子概念漏”，不是节级漏。

**关键代价**：

- attempt1 出现 **占位页**：slide 15“线性函数的图像：待续”，因为全局节清单被模型理解成“本批也要提一句”。改成“只写本批/承接、禁止待续页”后，占位页消失。
- attempt2 出现 **页数膨胀 + 填充页**：23 页（计划 18），slide 12“本批回顾”是回顾页，slide 20“线性函数 y=x 的图像”实际复用 1.2 的镜面反射内容来满足 1.5 的“必须出现”；1.2.3 给了 3 页，1.5 给了 3 页。
- **1.2.4 与 1.3 平移仍丢**：节清单只保证“这一节出现”，不保证“这一节的所有子概念出现”。1.2.4 没有独立小节标题（书签有），1.3 平移是节内子点，模型在页数压力下省略。
- **ρ 变得“健康”但不可信**：attempt2 ρ=3.81，但分母是 23 页、含回顾/复用页；总密度达标不代表每页都在讲新东西。

## 4. 判定

| 问题 | 判定 |
|---|---|
| 节级清单是否修复 1.1.1/1.1.2/1.1.3/1.6 有理？ | **是。** 这是验证 2 最明确的正向结果。 |
| 是否足以解决信息密度偏移？ | **不够。** 它把“漏节”换成了“凑页”：页数膨胀、回顾页、跨节复用页、讲内重复。 |
| 为什么页数会超？ | 讲纲只给了“至少 1 页/节”，没有“每节最多 1 页/整讲上限”；`validateSlideSet` 只校验 6–30 页，不校验是否接近预算。模型自然多写。 |
| 为什么 1.2.4/1.3 平移仍丢？ | `sections` 只到书签节级；1.2.4 是正文子节（书签只到 1.2.3），1.3 平移是节内子点。节清单保证“这一节出现”，不保证“节内每个子概念出现”。需要 `must_keep[]` + 页内校验。 |
| ρ 是否可以作为验收？ | **不能单独用。** attempt2 ρ=3.81 看似健康，但含填充/复用页；必须同时看“每节页数、讲内重复率、子概念覆盖”。 |

## 5. 验证 3 建议（下一步）

1. **每节页数上限**：`sections[].pages=1`，整讲页数不超过 `sections.length+1`（本章 14 页）；`validateSlideSet` 增加“页数超过预算 +2 即失败/修复”，不再只卡 30。
2. **禁止填充页**：prompt 明确“不要写本批回顾页/待续页/下节预告页；每页标题必须对应本批某个小节或承接小节”；生成后机检标题与 `batch.sections` 的对应关系。
3. **子概念 must_keep**：每个 section 增加 `must_keep[]`（如 1.1.2: 分母/偶次根/对数；1.3: 复合/平移；1.6: 多项式/有理/指数/对数/绝对值），生成后逐条检查；1.6 的子概念可从正文 `(1)…(5)` 提取，不再只靠书签根标题。
4. **讲内重复检查**：`duplicate` 现在只查相邻讲；增加“同一讲内 shingle 重复率”，把“回顾页/复用页”挡在验收外。
5. **页预算与节预算分离**：`lecture.pages` 是计划值，生成后不要把 `series.lectures[].pages` 覆盖成实际页数；否则下一次重跑会用 23 页做预算，越跑越膨胀。验证 2 attempt2 的 18 页预算就是被 attempt1 的实际 18 页覆盖后的结果。
