## 1. 背景

- 现状：设置页把 6 个栏目纵向排成一列（`.blm-settings` 内 6 个 `.blm-group`）：语音 → 模型（只读）→ 配图 → 用量与费用 → 存储与回收站 → 诊断。页面由 `.blm-body` 整体滚动，见 [client/index.js](../../client/index.js#L6701)；样式见 [同文件 L245–248](../../client/index.js#L245)。
- 问题：长表单式瀑布流，查看「诊断」必须滚到底；顶部「已保存」与当前浏览位置脱节；栏目之间没有导航锚点。
- 诉求：改为**顶部横向标签栏 + 单栏内容区**，一次只展示一个栏目，一步直达；活动栏目对应的按钮带动效。
- 约束：只改呈现层。各设置项的能力、默认值、保存时机、文案与接口调用保持不变。

## 2. 范围

**做**

1. 设置页标题行（`← 书架` / `设置` / `刷新页面`）下方新增横向标签栏，6 个按钮，文字与顺序严格对应栏目：`语音` · `模型（只读）` · `配图` · `用量与费用` · `存储与回收站` · `诊断`。
2. 默认选中「语音」；同一时刻只显示一个栏目面板，其余面板不占位、不可聚焦。
3. 活动按钮有动效：**单一共享下划线指示条**在按钮间滑动 + 文字颜色过渡；切换即时生效、不刷新页面。
4. 键盘与读屏可用：`role=tablist/tab/tabpanel`、`aria-selected`、`aria-controls`；`Tab` 进入标签栏后用 `←/→` 切换、`Home/End` 跳首尾。
5. 标签栏滚动吸顶；切换栏目后内容从面板顶部开始。
6. 窄屏单行横向滚动（不折行、不变下拉），活动按钮自动滚入可视区。
7. 本次会话记住最后停留的栏目（`sessionStorage`）；点「刷新页面」后仍回到该栏目。
8. 未保存输入跨标签保持（价格表 JSON 草稿、API Key 输入框）；离开「语音」标签时停止正在播放的试听，切回可重播。

**不做**

1. 不新增/修改任何接口、数据文件与字段；`preference.json`、`*.json`、数据 schema 均不动；`host/*` 与 `host/api.js` 零改动。
2. 不改各栏目已有功能、校验、按钮、文案与后台作业；不改「查看历史」跳转用量页的现有路径。
3. 不做按标签懒加载：仍沿用进入设置页时一次性拉齐 `/settings`、`/voice`、`/diagnostics`、`/image/config`、`/usage/*`。
4. 不做设置页内二级导航、搜索、URL 路由/深链（「到设置 → 语音」不会自动跳标签）。
5. 不做移动端专属布局、汉堡菜单、下拉式栏目选择；不改书架与播放页。
6. 不调整保存粒度（保持各栏目原有的即时保存 / 按钮保存）。

## 3. 交互规格

| 项 | 规格 |
|---|---|
| 位置 | 设置标题行之下，全宽单行；与内容同处 `.blm-body` 滚动容器，`position: sticky; top: 0`，带背景与底部分隔线 |
| 排列 | 左对齐、按文字宽度自适应，按钮间距 4–8px；**不换行**，超出则横向滚动 |
| 默认 | 「语音」 |
| 切换 | 点击或键盘立即切换：无刷新、无新增请求；只替换可见面板，页面不重建 |
| 选中态 | 同一时刻恰好一个 `aria-selected="true"`；活动按钮文字高亮，非活动按钮 `--blm-dim` |
| 指示条 | 单一共享元素，宽度与位置取自活动按钮；首次渲染不播动画，之后每次切换平滑移动 |
| 滚动 | 切换后滚动到标签栏下沿，新面板首行可见；标签栏保持吸顶 |
| 提示位置 | 全局加载错误条固定在标签栏上方；各栏目自己的提示（含语音「已保存」）留在本栏目面板内 |
| 窄屏 | < 1040px 同样单行横向滚动；不折行、不下拉；活动按钮自动滚入可视区 |
| 状态 | 六个面板全部挂载，非活动面板用 `hidden` 隐藏 → 切走再切回不丢状态、不重复请求 |
| 试听 | 离开「语音」标签即停止播放并释放音频元素；保留「已就绪」缓存，切回可直接重播 |

## 4. 动效规格

- **形态（已拍板）**：2px 下划线指示条，颜色 `--blm-accent`，圆角 1px；活动标签文字由 `--blm-dim` 过渡到 `--blm-text`。
- **不改字重**：活动态只改颜色，不改 `font-weight`，避免按钮宽度抖动导致指示条反复测量。
- **时长与曲线**：指示条位移动画 180–220ms，`cubic-bezier(.2,.7,.2,1)`；文字颜色过渡 120ms。
- **只动合成属性**：位移用 `transform`，透明度用 `opacity`；不 `animate` 宽度以外的布局属性，避免跳帧。
- **节制**：不弹跳、不缩放、不循环闪烁、不加长时间 shimmer；快速连点只认最后一次落点，动画不排队、不残留。
- **降级**：`prefers-reduced-motion: reduce` → 取消滑动，直接切换；测量失败 → 退回「活动按钮自身下划线」的纯 CSS 方案，不留空白。
- **不打断操作**：动效期间可继续操作表单；动画不影响滚动与键盘焦点可见性。

## 5. 视觉、响应式与可访问性

- 标签 12–13px，栏高约 36–40px，内边距 6–10px；底边 1px `--blm-line`。
- 悬停：底色 `color-mix(in oklab, var(--blm-accent) 8%, transparent)`；暗色主题沿用 `body[data-ds-dark-theme]` 现有变量，不新增主题分支。
- 面板沿用现有 `.blm-group` 卡片外观（边框、圆角、`--blm-card` 底色），只去掉与标签重复的 `h3`。
- ARIA：`tablist` 带 `aria-label="设置栏目"`；每个 `tab` 有稳定 `id` 与 `aria-controls`，roving `tabindex`（活动 0、其余 -1）；每个 `tabpanel` 有 `role`、`id`、`aria-labelledby`，非活动加 `hidden`。
- 键盘：`←/→` 循环切换，`Home/End` 首尾；焦点环可见；标签内不拦截其它快捷键。
- 窄屏：320–1440px 均可单行浏览；不折行、不溢出、不产生横向页面滚动条。

## 6. 数据与接口边界

- 接口、宿主与数据文件零改动：`host/*`、`host/api.js`、`preference.json`、`series.json`、`slides.json`、`usage/*` 均不新增字段，schema 仍为 `2`。
- 标签选中态只存在前端：`sessionStorage` 键 `blm-settings-tab`，值为 6 个栏目之一；非法/缺失 → 回「语音」。
- 设置页数据仍由进入时的一次性请求提供，切换标签不触发新请求。

## 7. 验收

### AC-172（标签导航与单栏展示）

- **构造**：进入设置页；读 6 个 `tab` 的文案、顺序与 `aria-selected`；依次点击每个标签；点「刷新页面」。
- **断言**：① 文案与顺序完全一致，默认「语音」；② 每次只有一个 `tab` 选中、只有对应 `tabpanel` 可见，其余 `hidden` 且不可聚焦；③ 切换无整页刷新、无 `/settings` `/voice` `/diagnostics` `/image/config` `/usage/*` 之外的新请求；④ 标题行三个按钮位置与行为不变，刷新后回到最后栏目。
- **判定**：多栏同时可见、按钮名不符、刷新丢栏目 → 不通过。
- **机检入口**：`node test/parity-settings.test.mjs`（SSR 断言 6 个标签文案/顺序、默认面板可见、其余 `hidden`）+ 真机走查。
- **人工边界**：切换瞬间是否闪白；吸顶后是否遮挡标题行。

### AC-173（动效、状态与滚动）

- **构造**：语音 → 诊断 → 切回；快速连点多个标签；把窗口从 1440 拖到 900；开启系统「减少动态效果」；在语音页输入 Key 并播放试听时切到配图；改价格表草稿后切走再切回。
- **断言**：① 指示条 250ms 内与新按钮对齐，无残留、无错位；② `prefers-reduced-motion` 下无滑动；③ 切走再切回，Key 输入与价格草稿仍在；试听已停止且可重播；④ 切换后内容自顶部开始，标签栏仍吸顶。
- **判定**：指示条错位、输入丢失、后台继续出声 → 不通过。
- **机检入口**：SSR/源码契约断言（指示条样式与 `transition`、`prefers-reduced-motion` 媒体查询、`hidden` 互斥）；真机走查动效与状态。
- **人工边界**：动效观感是否“快而不飘”。

### AC-174（响应式、可访问性与回归）

- **构造**：在 320 / 768 / 1040 / 1440 宽下查看；切暗色主题；纯键盘 `Tab` → `←/→` → `Home/End`；跑完整回归。
- **断言**：① 标签栏单行、不折行不溢出，活动项可见；② 暗色下文字与指示条可辨；③ `Tab` 只进活动标签，方向键循环、`Home/End` 首尾；④ 服务端与数据零改动（`host/*`、`api.js`、数据文件无 diff，schema 仍 `2`）；⑤ `npm run test:v2` 全绿。
- **判定**：折行/溢出、键盘不可用、动到接口或数据 → 不通过。
- **机检入口**：`npm run test:v2`；`git diff --stat` 人工确认只含客户端与测试文件。
- **人工边界**：窄屏横向滚动的顺手程度。

## 10. 实现记录（2026-11-10）

- **需求零变更**：D1–D6 全部按冻结稿落地；未新增/修改接口、数据文件与字段，`host/*`、`host/api.js`、schema 均未动。
- **指示条首帧不滑**：`ink` 初始为 `null`，首次测量后才渲染指示条，避免从 0 位置滑入；之后切换才走 200ms 过渡。
- **会话记忆白名单**：`sessionStorage` 读取只认 6 个栏目 id，非法值回「语音」；SSR / 隐私模式下静默回默认。
- **键盘自动激活**：方向键即切换栏目并把焦点移到新标签（roving `tabindex`），`Home/End` 跳首尾；不拦截其它按键。
- **滚动克制**：只有内容顶部已被吸顶标签栏遮住时才滚回；从顶部切换不会把标题行滚走。
- **可测性**：把 `settingsTabIndexForKey` / `readSettingsTab` / `saveSettingsTab` 挂到 `__helpers`，用纯函数断言键盘与会话记忆，不依赖 DOM。
- **验证证据**：`node test/parity-settings.test.mjs` 16 项全绿；`npm run test:v2` 43 文件 / 394 项（392 通过 / 2 跳过）全绿；`git diff --stat` 仅客户端、测试与文档（README / SRS / 需求 / 进度），无宿主、接口或数据文件变更。
- **人工边界**：真机上的指示条观感、320–1440px 横向滚动、暗色主题与读屏行为需在发版前走查（本环境无浏览器自动化）。
