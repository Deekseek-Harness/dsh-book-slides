| 文件 | 是什么 | 状态 |
|---|---|---|
| [初步需求.md](初步需求.md) | 2026-11-03 的第一版需求原文：角色设定、核心流程、JSON 结构草案 | 只作历史存档；与实现冲突时以规范为准 |

## 为什么冻结

- 发布之后，这两份文件要能回答「v1.0 当时承诺了什么」。事后改字，交付记录就失去意义。
- 后续变更不写回这里：行为变化记进 [CHANGELOG.md](../../CHANGELOG.md)；新需求另开文档
  （例如 `doc/requirements/` 下新增一份并标上版本），由 CHANGELOG 指向它。
- 冻结指的是**内容**：文件名、相对路径、被别的文档引用都不受影响。仓库里对它们的引用是
  [README.md](../../README.md) 与 [store.js:4](../../store.js#L4)。

## 读的时候注意

- 文中的 `tutor.js` 是早期命名，实现落在 `generate.js` + `slides.js`。
- 文中「上级目录的 规范需求.md」「测试书籍/」这类路径按当时的开发目录理解，现在：
  需求文档在本目录，真值在 [test/truth](../../test/truth/README.md)。
- 测试数量、命令、当前限制以 [README.md](../../README.md) 和 [CHANGELOG.md](../../CHANGELOG.md) 为准：
  需求文档里的 162 项是 M5 修复时的快照。
- 附录 J 的「明确不做」仍然有效：实时语音、声音复刻、SSML、多供应商自动回退、Key 加密都不在 v1.0 里。
