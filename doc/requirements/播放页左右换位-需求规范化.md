| 项 | 内容 |
|---|---|
| 版本 | v0.2（**2026-11-10 拍板冻结**，D1–D7 全部按推荐） |
| 产品 / 包 / 文档 | 产品 `2.4`、包 `2.4.0`（已发布，tag `v2.4.0`）、本 SRS `v1.26` |
| 落点 | SRS [FR-18.2](规范需求2.0.md)、AC-169 ~ AC-171、`view.json` + `/series/view` |
| 状态 | **已发布（2026-11-10，2.4.0）**；`npm run test:v2` 43 文件 / 389 项全绿；README、CHANGELOG、包版本与实现进度均已同步 |

## 1. 背景

- 现状：播放页是「原文 | 分隔条 | 幻灯片」三列，原文在左占 55%，幻灯片在右；比例记忆是**全局一份**（`preference.json` 的 `split`）。
- 诉求：原文与幻灯片可左右对调；**默认原文在右、幻灯片在左**；布局记忆继续保留。
- 拍板时的追加约束：**布局粒度按系列**（不同系列可有不同布局，各自记忆）；**交换按钮下沉到系列播放界面**，不做全局开关。

## 2. 范围

**做**

1. 系列播放页顶栏「⇄ 换位」，点击即时生效、不刷新、不打断播放。
2. 默认 `ppt-left`（左幻灯片 / 右原文）；每个系列一份布局记录（方向 + 原文宽度）。
3. 新增 `series/<seriesId>/view.json` 与 `GET/POST /series/view`；服务端夹紧非法值。
4. 老系列无记录：方向默认 `ppt-left`、宽度取现有全局 `preference.split`；首次操作才落盘，不批量迁移。
5. 删除系列即删目录，布局记录随之消失。

**不做**

1. 全局默认布局设置、“应用到所有系列”、按书级记忆。
2. 第三种排布、自由拖拽重排、换位动画、键盘快捷键。
3. 改 `series.json`（避免与配音/配图作业写回互踩）、`slides.json`、`progress.json`；数据 `schema` 仍为 `2`。
4. 改 PDF 渲染、锚点、缩略图、连播、字幕内容与音频逻辑。
5. 导出包携带 `view.json`（与 `progress.json` 同级排除）。

## 3. 交互规格

| 项 | 规格 |
|---|---|
| 入口 | 仅该系列播放页顶栏，与「系列目录 / 全屏 / 打开 PDF」同排；`aria-pressed` 表示当前是否 `pdf-left` |
| 默认 | 无记录 → `ppt-left`（左幻灯片 / 右原文），原文宽度取 `preference.split`（默认 0.55） |
| 生效 | 当帧交换两栏内容与顺序；不重建音频、不回页首、不丢当前页与滚动位置；全屏 / 目录 / 过渡卡状态保持 |
| 宽度 | 换位只换位置，**两栏宽度不因换位改变**（`split` 是原文窗格占比，分隔条贴着原文边缘） |
| 记忆 | 方向与比例写入该系列 `view.json`；重开、重启 DSH、切窗口刷新后保持；**系列之间互不影响** |
| 写入 | 点换位即写；拖分隔条在 `pointerup` 写；双击复位也写；多窗口最后写入生效 |
| 窄屏 | <1040px 隐藏「⇄ 换位」；堆叠顺序仍为上幻灯片 / 下原文 |
| 不变 | 翻页、缩略图、连播、系列目录、字幕（跟随幻灯片列）、`--restore`、聚焦刷新、键盘映射不变 |

## 4. 数据契约

```jsonc
// ~/.dsh/book-slides/books/<bookId>/series/<seriesId>/view.json
{ "schema": 1, "series_id": "xxxxxxxxxx", "layout": "ppt-left", "split": 0.55, "updated_at": "2026-11-10T13:00:00.000Z" }
```

- `layout ∈ ppt-left | pdf-left`；缺失 / `null` / 数字 / 其它字符串 → `ppt-left`。
- `split` ∈ 0.25–0.75（原文窗格宽度占比）；非法 → 该系列的默认值（`preference.split`，再非法则 0.55）。
- `GET /series/view?seriesId=` → `{ok, view}`；无记录返回默认值且**不落盘**。
- `POST /series/view {seriesId, layout?, split?}` → 只写传入字段，读回完整 `view`。
- `preference.json`：不新增 `layout`；`split` 保留，仅作「该系列无记录时的初始值」，播放页不再回写。
- 书档：`view.json` 不入包，导入后该系列回默认布局。

## 5. 验收

- **AC-169** 系列内默认布局与即时换位：默认左幻灯片 / 右原文；点击当帧交换、无需刷新；不重建音频、不回页首、全屏与目录状态保持；再点回到原布局；书架/设置页无换位入口；AC-107/108/123/142/143/166/167 行为不变。
- **AC-170** 按系列记忆与隔离：A 系列 `pdf-left` + `split=0.3` 落 `view.json`；B 系列仍 `ppt-left` 默认比例且不落盘；重开、重启各自保持；删除 A 后无残留；新建系列回默认。
- **AC-171** 异常值、损坏文件与导出边界：非法值回落/夹紧且不 500；坏 `view.json` 按默认渲染不崩；导出包不含 `view.json`；`series.json` / `slides.json` / `progress.json` 无新字段；`preference.json` 不出现 `layout`。

判据、构造与机检入口以 SRS [FR-18.2](规范需求2.0.md) 为准。

## 7. 与 v0.1 的差异

| 项 | v0.1 | v0.2（冻结） |
|---|---|---|
| 记忆粒度 | 全局 `preference.json` | **按系列** `view.json` |
| 入口 | 播放页顶栏（语义偏全局） | **下沉到系列播放页**，无全局开关 |
| 存储 | `preference.json.layout` | **新文件 + 新接口**；`preference.split` 降为初始值 |
| 比例 | 全局 | 随方向按系列（D4） |
| 验收 | AC-169 / 170 | AC-169 / 170 / 171（补系列隔离与导出边界） |
