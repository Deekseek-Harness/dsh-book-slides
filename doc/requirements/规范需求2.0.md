## 0 一页速览

**一句话**：用户勾选一组章构成一个 **Part**，系统按容量把它规划为 **N 讲**，先用一次调用产出 **讲纲**（主线 / 讲次 / 接缝句 / 术语），再逐讲生成，并在讲与讲之间做**可验证的缝合**，最后以**系列**形态连播、连练、连导出。

**关键变化**

| 维度 | v1.6 | 2.0 |
|---|---|---|
| 单元 | 勾选即一个模块，1–5 章 | Part（不限章数）→ N 讲，讲 ≤6 万字 |
| 容量 | 超 5 章 / 6 万字直接拒绝 | 超容量自动拆讲；单章超长章内拆“上/下” |
| 接缝 | 无（各模块互不知道） | 讲纲统一主线与术语；接缝句一次生成、两处复用；后验机检 |
| 兼容 | 1.x 数据与模块可读 | **数据/契约不兼容**：同根新 schema；升级时自动备份旧根，之后重新导入；无独立单讲 |
| 功能 | 1.x 可见能力 | **全部保留**；P0/P1 与验收见 §2.5、§2.6 |
| 发布 | 独立包，可与其它版本并存 | **同包名覆盖安装**，不与 1.x 并存 |

**演示路径（8 步）**：导入 PDF → **生成章节目录** → 勾选“函数”7 章 → **确认此部分（Part）** → 预览“2 讲 / 42 页 / 约 42 分钟” → 开始生成 → 连播（第 1 讲末页承接进第 2 讲封面）→ 导出整套或按讲导出。

```
导入 PDF ──▶ 分章构建 ──▶ 确认 Part ──▶ 预览讲纲 ──▶ 开始生成 ──▶ 后验缝 ──▶ 系列可播
             chapters.json   parts.json      plan（只读/可存） series.json   stitch 报告
```

**功能边界**：本规范面向 2.0 产品。1.x 的用户可见能力全部保留（§2.6）；不兼容只指存储 schema、目录布局与内部模型。任何能力缺失都按缺陷处理。

**里程碑**：里程碑、验收门与功能对等实施顺序见 §12；P0 先完成，P1 随后，二者均在 2.0 发布前关闭。

## 1 版本定位（不兼容重写）

### 1.1 为什么需要 2.0

v1.6 的三个约束互相纠缠，导致两类“功能缺失”：

1. **5 章 / 6 万字是硬拒绝**（[generate.js:49-50](dsh-book-slides/generate.js#L49-L50)、[generate.js:105](dsh-book-slides/generate.js#L105)）：超限只能手动拆成多次生成，得到互不相关的模块，知识讲解的连贯性丢失。
2. **单章超 6 万字无法精讲**：选择阶段即被拒，用户看到的是“功能不可用”，而非“拆成两讲”。
3. **缺失“模块之上”的容器**：既不能表达“这 7 章属于同一个部分”，也不能表达“这 3 讲属于同一个系列”。

三者的共同根因是：**约束对象错了**。单次调用上下文早已由分块解决（单批 ≤1.2 万字，章内 ≤8 千，[slides.js:23-24](dsh-book-slides/slides.js#L23-L24)）；6 万字实为 **30 页 × 每页对应原文 2000 字** 的交付带宽（§3.3）。2.0 不改带宽，改的是“超过带宽时怎么办”。

### 1.2 条款关系

> 2.0 不承担 1.x 的**数据与契约**兼容义务；功能能力仍须保留。1.x 条目分两类：数据/接口条款按本表处置；**功能条款以 §2.6“1.x 能力保留总表”为准**，未列入总表、也未在 2.0 实现的 1.x 功能，按缺陷处理。

| v1.6 条款 | 2.0 处置 | 说明 |
|---|---|---|
| FR-4 章节多选与模块（5 章 / 6 万字上限） | **废弃** | 由 Part（FR-12）与讲次规划（FR-13）取代；不再有 5 章 / 6 万字硬拒绝 |
| D11 分块生成（12000 / 8000 / 300） | **沿用常数** | 批参数保留，但不承诺与 1.x 行为一致 |
| FR-5 生成流水线（四阶段） | **重写** | 系列编排 + 单讲流水线（FR-14–FR-17）；阶段名仅作参考 |
| D13 模块缓存键 = 章集合 | **废弃** | 新两级键（§6.9），与旧键不互通 |
| FR-6 播放器 | **重写** | 播放器以系列为单位（FR-18）；不存在“游离单讲”入口 |
| FR-10 导出 PPT | **重定义** | 按讲 / 整套两种（FR-19）；OOXML 实现可复用，数据契约不同 |
| FR-11 练习与复习 | **重定义** | 按系列组卷（FR-19）；题库结构可借鉴，不迁移 |
| §5.1 磁盘布局 | **废弃** | 同根新布局与 `schema=2`（§6.1） |
| 旧模块（v1.6） | **不兼容** | 不读取、不迁移；2.0 只认 `schema=2` 的数据根（FR-20） |

“重写/重定义”只表示数据契约与对象变化，**不表示子能力可以减少**；子能力以 §2.6 保留总表为准。

### 1.3 不兼容声明

放弃兼容的理由：单讲模块、旧缓存键、旧书档会把“系列”做成两条路径——每条都要测、都要修，历史包袱最终会拖垮接缝机制。代价是一次重导，换单一数据模型与单一代码路径。

六条边界：

1. **同根不兼容**：2.0 使用 `~/.dsh/book-slides/`，以 `meta.json.schema=2` 标识；检测到旧 schema 时，先自动备份整个旧根，再初始化同路径的 2.0 数据；旧文件不被解析。
2. **不迁移、不导入**：不提供 1.x 模块/书档转换；升级方式 = 自动备份 → 初始化 2.0 → 重新导入 PDF。
3. **无独立单讲**：所有讲都属于某个系列（N=1 亦然），不存在游离模块。
4. **同根切换用备份**：1.x 与 2.0 共用同一目录，但互不识别对方的 schema；回滚 1.x 时把自动备份恢复回同根。
5. **不并存**：沿用同一包名 `dsh-book-slides` 与同一插件 id，2.0 覆盖安装 1.x；插件列表始终只有一个「精讲」入口。
6. **功能对等**：不兼容仅覆盖存储 schema 与内部模型；1.x 的用户可见能力（原文分屏、导入、分章、书架卡面、书籍管理、设置、作业、语音、练习、配图、导出）必须保留。删除能力不属于“不兼容”的合理代价。

## 2 范围

### 2.1 目标

1. 一次覆盖一个 Part（规划上限 48 章 / 8 讲），无需手动拆分。
2. 讲与讲之间具备**可机检**的衔接：接缝句一致、页码与章序一致、术语一致、重复率受控。
3. 单章超长时自动章内拆分，切点落在节边界，而非任意段落。
4. 系列可连播、可部分可用（某讲失败不阻塞其余讲）。

### 2.2 非目标

- 不做整本书一次性生成（Part 之外不设全局主线）。
- 不做“部分语义”推断：插件不判断用户为何把这些章归为一组（D62）。
- 不做跨 Part 的连续播放或跨书系列。
- 不做有声书级的无缝合成（讲间保留可感知的过渡，但不做音频拼接）。
- **不兼容 1.x**：同根但只认 `schema=2`；旧 schema 不解析、不迁移，升级时仅整体备份（§1.3）。版式与字段上限可沿用实现，但不构成兼容承诺。
- **不与 1.x 并存**：不发布第二包名、不检测/引导双装；2.0 就是唯一在装的「精讲」。
- **不删功能**：不兼容不等于功能缩水。1.x 的可见能力要么在 2.0 保留，要么在 §2.5 逐项登记为“显式降级”并给出恢复版本；未登记的缺失按缺陷处理。

### 2.3 用户场景

| 场景 | 输入 | 期望 |
|---|---|---|
| S1 一个知识块一次听完 | “函数”7 章，8.4 万字 | 自动 2 讲；连播不断线；听完知道下一讲接什么 |
| S2 单章超长 | 单章 9 万字 | 拆成“上/下”两讲，不报错；切点在节边界 |
| S3 新装 2.0 | 本机已有 1.x 数据（同根） | 自动备份旧根到 `book-slides.backup-<时间>/`，2.0 初始化空书架；重新导入 PDF |

### 2.4 成功判据

| 层 | 断言 | 依赖落盘 | 不成立的表现 |
|---|---|---|---|
| L1 能覆盖 | 10 章 / 12 万字的 Part 一次规划完成，章无遗漏无重复 | `series.json` | 仍需手拼多个模块 |
| L2 能续听 | 系列内从第 1 讲第 1 页连播到最后一页，无需人工点下一讲 | 播放器系列态 | 播完即停、回列表手动找 |
| L3 能验证 | 接缝断言 100% 通过；重复率 ≤0.5；术语禁用词 0 | stitch 报告 | “接缝好不好”只能靠听感 |
| L4 单一路径 | N=1 与 N>1 走同一数据模型（Part + 系列）；不存在“游离单讲”分支 | `series.json` | 出现两套代码路径，兼容分支重新长出来 |

## 3 术语与概念

### 3.1 层级

```
部分 Part  →  讲 Lecture  →  批 Batch  →  页 Slide
（用户勾选）    （交付单元）     （调用单元）   （阅读单元）
```

### 3.2 名词表

| 术语 | 定义 | 2.0 中的位置 |
|---|---|---|
| 部分 Part | 用户人工勾选的一组原章节；插件不解释其语义；同一本书内 Part 两两无交集 | 根实体（`parts.json`） |
| 讲 Lecture | 一次独立交付的精讲，6–30 页，≤6 万字（工程上限 8 万） | 交付单元，必属系列；不再有独立模块 |
| 系列 Series | 一个 Part 的 N 讲及其讲纲、接缝、进度 | 唯一的播放/练习/导出容器 |
| 批 Batch | 一次模型调用覆盖的原文块（≤1.2 万字，章内 ≤8 千） | 生成内部单元，常数沿用 |
| 页 Slide | 一页讲义（cover / content_text / quote） | 阅读单元 |
| 讲纲 Syllabus | 系列单一事实源：主线、讲次、接缝句、术语、切点建议 | 新增 |
| 章介绍 Brief | 每章 60–100 字的定位说明 + 节标题 + 转折标记 | 新增 |
| 接缝句 Seam sentence | 相邻讲之间的一句过渡话，≤60 字，两处逐字复用 | 新增 |
| 预缝 Pre-stitch | 生成时即按接缝契约书写（不做事后补写） | 新增 |
| 后验缝 Post-stitch | 生成后的机检与定点修复 | 新增 |
| 压缩率 ρ | 本页对应原文净字数 ÷ 本页讲义字数 | 显式指标（§3.3） |

### 3.3 压缩率 ρ 与讲容量

```
ρ（本页）= 本页对应原文净字数 ÷ 本页讲义字数
```

- **分子**：该页 `source_pages`（及 `source_anchor`）覆盖、并被本页实际讲解的原文段落净字数；去掉页眉页码与空白后计数，**不等于物理 PDF 页的整页字数**。一页讲义可对应半页、一页或多页原文；无锚点时按 `source_pages` 区间估算。
- **分母**：标题 + 要点 + 引文 + 朗读稿（不含 `image_prompt`、`source_quote`）。按字段上限计算约 **624，按 600 计**（title 24 + 要点 5×40 + 引文 120+60 + 朗读 220）。

三档容量：

```
讲容量（设计值）   = 30 页 × 每页对应原文 2000 字 = 60000 字   （ρ = 3.3）
讲容量（工程上限） = 30 页 × 每页对应原文 2667 字 = 80000 字   （ρ = 4.4）
理论警戒          = 30 页 × 每页对应原文 3600 字 = 108000 字  （ρ = 6，不建议逼近）
```

ρ 分级：`<2.5` 偏松；`2.5–4.5` 健康；`4.5–8` 警戒（记 `density_warn`）；`>8` 拒收（必须再拆或转“速览模式”并明示）。

> ρ 只约束比例，不约束绝对信息量；后者由字段下限（`audio_script` 40–220 字、要点 1–5 条）与页数预算共同保证。

### 3.4 接缝五处与三态

| 接缝 | 位置 | 缝合者 |
|---|---|---|
| 播放缝 | 讲 N 播完 → 讲 N+1 第 1 页 | 播放器（FR-18） |
| 内容缝 | 讲 N 落点 → 讲 N+1 起点 | 讲纲接缝句（FR-15/16） |
| 切点缝 | 章与章、章内部切分处 | 讲次规划（FR-13） |
| 批缝 | 讲内批与批之间 | 生成注入（FR-16） |
| 术语缝 | 同一概念的不同叫法 | 术语表机检（FR-17） |

系列级缝合状态：

| 状态 | 含义 | 用户可见 |
|---|---|---|
| `unstitched` | 有讲但无接缝句（讲纲失败降级） | 连播可用，列表标注“本系列未做衔接” |
| `stitched` | 接缝句已注入并通过机检 | 正常 |
| `verified` | 机检与抽听均通过 | 正常，可导出 |

### 3.5 Part 的唯一定义

Part 是用户人工确认的一组原章节：`{id, title, chapters[], source}`。章节取自 `chapters.json` 的内容章（`front` 除外），顺序无关，按章号升序使用。Part 只是生成的基础对象：确认 Part 独立于预览/生成，预览与生成不得创建或修改 Part。

插件**不解释语义**：不判断“为什么在一起”，不从书的“第 X 部分”自动切分，不因标题相似建议合并/拆分。书的 part 条目仅可作为“一键选中”的便利与标题默认值。

**唯一硬约束**：同一本书内，任意两个 Part 的章集合两两不相交（`∀i≠j: parts[i].chapters ∩ parts[j].chapters = ∅`）。

## 4 决策（D62–D75）

| 编号 | 问题 | 决策 | 理由 |
|---|---|---|---|
| **D62** | Part 由谁定义？ | **用户勾选即定义**；插件不解释语义，不做自动归并 | 语义推断错误会经讲纲放大到整个系列；用户意图是唯一可靠来源 |
| **D63** | 两个 Part 能否共享章？ | **不能**；章归属唯一；N=1 的单讲同样登记为 Part | 同章落入两个系列会让练习、进度、导出出现归属歧义 |
| **D64** | 一讲多大？ | **30 页 × ρ3.3 = 6 万字**为设计值；**8 万字**为工程上限；超出即拆讲 | 由 ρ 与页数上限推导，而非拍脑袋；8 万留出锚点与朗读覆盖余量 |
| **D65** | 谁保证 N 讲像一门课？ | **讲纲**为单一事实源（主线/讲次/接缝句/术语/切点），每讲注入其切片 | 两次独立生成必然漂移；单一事实源是唯一可靠来源 |
| **D66** | 回顾/预告怎么写？ | **接缝句一次生成、两处逐字复用**：讲 i 末页结尾 + 讲 i+1 cover 开头 | 两讲各自写必然两种口径；逐字复用可机检 |
| **D67** | 缝合在生成前还是生成后？ | **预缝**（生成时注入契约）+ **后验缝**（生成后机检与定点修复） | 先机检、后调模型，成本最低且确定性最好 |
| **D68** | 切点怎么选？ | 优先**弧边界**（不拆同主题相邻章、只在章末切）；章内切分优先**节标题**，其次页边界，最后段落累计 | 切在语义停顿处，缝的需求最小；切在段落中间，缝也救不回 |
| **D69** | 讲纲失败怎么办？ | 退回**规则切分**（贪心装满容量、不拆主题弧），系列 `unstitched`，仍可连播 | 缝是最软的一层，不能因讲纲失败让整个系列不可用 |
| **D70** | 后验缝要不要调模型？ | 默认**只机检**（5 项指标）；仅当修复需要改写时才调模型，且优先只修衔接页 | 能用字符串/集合判断的，不调用模型 |
| **D71** | 修复粒度？ | 页 → 讲 → 相邻两讲 → 整系列，按问题类型取最小单元（§FR-17） | 修轻无效，修重昂贵；粒度必须与问题匹配 |
| **D72** | 改一个切点要重跑多少？ | **`replanFrom(k)`**：保留 1..k−1，只重算 k..N 的装章、页预算与接缝 | 级联成本不可接受；做不到局部化，手动切点等于不可用 |
| **D73** | 缓存与 Part 编辑 | 两级键（seriesKey / lectureKey）；系列保存**章快照**；Part 变更只标记“基于旧快照”，不静默改动已生成内容 | 增量与一致性同时成立；用户不会因改个名字就丢内容 |
| **D74** | 系列怎么播？ | **连播**：讲末页播完 5 秒过渡卡进下一讲；系列进度“已听 24/42 页”；系列目录可跳讲 | 播放缝是感知最强的接缝，修复成本最低 |
| **D75** | 练习与导出按什么单位？ | 练习**按系列组卷**（题仍按章）；导出**默认按讲**，可选合并为整套 | 练习要覆盖整个 Part；导出要兼顾“一次讲完”与“整套交付” |
| **D76** | 是否兼容 1.x？ | **不兼容**：同根新 schema、不迁移、无独立单讲；N=1 也走系列 | 双模型/双路径的成本高于一次重导；2.0 的数据与接口按系列重新设计 |
| **D77** | 1.x 与 2.0 能否并存？ | **不能**：同包名 `dsh-book-slides`、同插件 id，2.0 覆盖安装；不发布第二包名 | 并存会带来两套路由、两块面板与两套 schema 的长期维护成本 |

## 5 功能需求

### FR-12 Part 定义与管理

- **描述**：Part 是生成的基础对象，但确认 Part 与开始生成是**两个独立动作**：用户可先确认 Part、稍后预览/生成，也可由 AI 建议草稿后人工确认；生成过程不得创建、修改或删除 Part。
- **规则**
  - **草稿**：勾选章节只形成临时草稿，不写 `parts.json`。
  - **确认 Part**：用户点「确认此部分」调用 `POST /part {bookId, chapters[], title?, partId?, source?}`；成功后 Part 落盘，与是否预览/生成无关。
  - **来源扩展**：`source ∈ manual | book_toc | ai_suggest`，只记录来源，不影响生成。AI 辅助只产生草稿/建议，必须经用户「确认此部分」才落盘；生成只依赖 `partId`，不关心来源。
  - **计划预览（不落盘）**：`POST /plan/preview {bookId, chapters[], partId?}` 对草稿或已确认 Part 生成 plan，不写 Part/series；可取消，取消不影响任何产物。
  - **系列容器**：`POST /series {bookId, partId, title?, plan?}` 只创建 `draft` 系列（不带作业）；带 `plan` 时直接进入 `planned`。
  - **系列讲纲**：`POST /series/plan {seriesId, plan?, force?}` 写入/重算系列 plan；成功后状态 `planned`；不启动生成。
  - **文本生成**：`POST /series/start {seriesId, lectures?}` 只对 `planned` 系列启动文本作业；不做配音；不创建/修改 Part。
  - **单讲生成**：`POST /series/lecture/generate {seriesId, n}` 只生成指定讲；`/series/retry` 等价于重跑失败讲。
  - **配音**：由独立 `POST /revoice` 触发（FR-23），不属于文本作业。
  - **组合流程不合并接口**：UI 可顺序调用 `/series` → `/series/plan` → `/series/start`，但三者是独立动作/状态；任一步失败不自动跨步，也不创建/修改 Part。
  - **校验**：`chapters` 非空、无重复、均为内容章（`front` 除外）、章数 ≤48（8 讲 × 每讲 6 章）。
  - **不相交**：与本书已有 Part 求交集；非空即 `E_PART_CONFLICT`，交互层三选：**并入已有 Part** / **改选** / **先把冲突章从原 Part 移出**；三选都通过 `POST /part` 或 `/part/update` 立即落盘，不等生成。
  - **编辑**：可改名、增删章；增删重新执行不相交校验；成功后 `part_version+1`，其系列标记“基于旧快照”。
  - **删除**：只删分组，不删系列与模块；系列保留章快照与 `part_id` 历史值。
  - **单讲即 Part**：N=1 同样登记，`stitch` 直接为 `verified`（无需接缝）。
  - **确认反馈**：`POST /part` 成功后，详情页必须重新拉取 `GET /parts` 并渲染：Part 以组头出现（标题、章数、字数、系列数、「已确认」徽标），组内章标“属于《…》”且默认不可直接反选；临时勾选清空并滚动到该组。
  - **失败不落幽灵组**：确认/编辑失败都不新增或改写 Part；保留当前草稿以便重试。
- **AC-92** 勾选 7 章并点「确认此部分」：`parts.json` 出现 1 条记录，7 章归属该 Part；随后预览、生成；取消生成后 Part 仍在；再勾选已属于该 Part 的 2 章 + 1 章新章并确认，弹冲突三选，取消后无新 Part、无模型调用。
- **AC-93** 把 Part 改名并加 1 章，`part_version` 递增；其系列显示“基于旧快照（v1）”，内容未变。
- **AC-94** 删除 Part 后，其系列仍可打开、播放、导出；`series.part_id` 仍指向历史 id。
- **AC-95** 接口提交含 `front` 章的 `chapters` → `E_PART_FRONT`；提交 49 章 → `E_PART_TOO_MANY`；提交重复章 → `E_PART_DUP`。
- **AC-129** 点「确认此部分」后列表立即出现组头（标题、7 章、字数、系列数）与「已确认」徽标，7 章标“属于《…》”且不可直接反选，临时勾选清空并滚动到该组；刷新/重开/切换书后一致；未确认时可对草稿 `/plan/preview` 但不可开始生成；确认后可建系列/改讲纲/生成；预览、生成、取消生成都不改变 Part；AI 建议草稿必须确认后才落盘；确认失败不产生幽灵组且草稿保留。

### FR-13 讲次规划

- **描述**：把草稿章集合（预览）或 Part 的章集合按容量与弧边界切成 N 讲，给出每讲的章、页预算与切点建议。
- **规则**
  - **讲数**：`N_est = max(1, ceil(totalChars / 60000))` 只是容量下限估计；实际讲数由装章决定（每讲 ≤6 章且刚好装满），超过 8 讲报 `E_SERIES_TOO_MANY`，不静默截断。
  - **装章**：贪心，每讲 ≤6 章且目标 ≤6 万字；若节边界不可切分导致略超，允许至 8 万（I4）；**不拆同主题相邻章**（由 brief 的 `role`/`turning` 判断，标记 `cut_warn` 但不阻断）。
  - **页预算**：`pages_i = clamp(round(chars_i / 2000), 6, 30)`；按字数比例而非平均；系列总页数可超过 30（上限为每讲）。
  - **切点**：只在章末移动；章内切分优先级 `节标题（第X节 / X.Y / 一、 / 【…】）→ 页边界 → 段落累计`；单章 >6 万字时拆“上/中/下”，每段 ≤6 万字。切点落在页内时，相邻两讲共享该页（至多重一页），`source_pages` 允许重叠。
  - **章不连续**：允许（Part 由用户勾选）；`range` 仅作包络，页预算按章逐章求和，包络空隙不计入。
  - **预览**：生成前返回讲次、每讲章与页数、预计时长（页 × 60 秒，含停顿与翻页），供用户确认或改切点。
- **AC-96** 7 章 8.4 万字 → 预览 2 讲（5+2 章，首讲刚好装满 6 万字）、30+12 页、预计 42 分钟（±10%）。
- **AC-97** 单章 9 万字 → 规划为“上/下”2 讲，不抛 `E_SELECTION_TOO_LARGE`；切点落在节标题行。
- **AC-98** 章 1、3、5 构成 Part → 2 讲，页预算按 3 章字数求和，页区间允许空档，`source_pages` 不越出各章范围。

### FR-14 章介绍（briefs）

- **描述**：为讲纲提供结构信息；每章一条 brief，含定位、节标题、转折标记。
- **规则**
  - 字段：`{n, gist(≤100 字), sections[], role, turning}`；`gist` 说明“本章讲什么”，`role` 说明与前后章关系。
  - `sections` **必须逐字取自该章原文中的行**（机检：能在该章文本中检索到）；不满足则丢弃该条，退回“标题 + 首尾段”。
  - 一次调用覆盖 ≤10 章；超过分两批；失败不阻断，回退原文首尾段（D69 的同一原则）。
  - 落盘 `briefs.json`，可复用、可人工改；修改后使下游讲纲缓存失效。
- **AC-99** 7 章 briefs 生成成功，`sections` 全部可在原文检索到；人为篡改一条，校验失败并回退该章。
- **AC-100** 模型返回坏 JSON → 重试 1 次；仍失败则整个 briefs 回退首尾段，系列仍可规划。

### FR-15 讲纲

- **描述**：一次调用把 Part 规划为 N 讲，产出主线、每讲目标与落点、接缝句、术语表、切点建议。
- **规则**
  - **输入**：书名、Part 标题、briefs、预算参数（页数上限 30、目标 ρ=3.3、章数区间 [2,6]）、用户偏好（期望讲数、指定切点）。
  - **输出 schema**：`{throughline, lectures[{n, chapters[], title, goal, in, out}], seams[{from, to, concept, sentence}], terms[{name, forbid[]}], cut_notes}`。
  - **校验**：讲次连续；章覆盖 = Part 章集合且无重叠；每讲 1–6 章且字数 ≤8 万（I4）；`seams` 数 = N−1；`sentence` ≤60 字；`terms[].name` 至少出现在一个 brief 或章标题中。
  - **重试**：解析或校验失败回灌一次；两次失败按 D69 降级。
  - **注入**：每讲生成时只取用其切片（本讲 goal/in/out、相邻讲标题、已覆盖概念、术语表）。
- **AC-101** 2 讲系列返回 1 条 seam；把 seam 数改成 0 或 2，校验失败并重试；两次失败后系列 `unstitched` 且仍可生成。
- **AC-102** 术语表出现原文与 briefs 均未出现的词，判定“凭空发明”，要求重试。

### FR-16 文本生成与预缝

- **描述**：逐讲生成文本讲义（structuring → validate → anchor），在提示词与校验中加入接缝契约；**不包含 TTS**，配音由 FR-23 的独立作业完成。
- **规则**
  - **文本三阶段**：文本生成、结构校验、锚点回填；不调 TTS、不写音频。
  - **音频字段**：初始 `audio_file=null`、`audio_provider="none"`；播放器回退浏览器朗读或提示“未配音”。
  - **契约切片**：本讲 `goal/in/out`、主线、相邻讲标题、已覆盖概念清单（“以下概念已讲过，一句话唤起即可”）。
  - **批缝**：第 2 批起，开头强制一句承接（上一批末段要点回写）；原文 carry 由 300 字升级为“300 字原文 + 上一批标题与要点”。
  - **预缝注入**：讲 i+1 的 cover `audio_script` 以 `seam[i].sentence` **逐字开头**；讲 i 末页 `audio_script` 以它**逐字结尾**；总长仍 ≤220 字。
  - **断言**：`cover.audio_script.trim().startsWith(seam.sentence)` 与 `last.audio_script.trim().endsWith(seam.sentence)`；不通过只重试该页，不重跑整讲。
  - **不设视觉回顾页**：用 cover 的 220 字承载承接与导览；若产品要求视觉回顾页，须从 30 页预算内扣除。
  - **反模式**：不得把上一讲全文注入提示词；不得让两讲各自生成回顾/预告；不得在章内移动切点（仅章末/节边界）。
- **AC-103** 2 讲系列生成后，第 2 讲 cover 首句与第 1 讲末页末句逐字相同（字符级比对通过）。
- **AC-104** 人为把第 2 讲 cover 首句改掉一个字，重跑断言 → 只触发 1 次页级修复，第 1 讲 `lecture.json` 的 mtime 不变。

### FR-17 后验缝与修复

- **描述**：生成后先机检，按最小粒度修复；产出可查看的 stitch 报告。
- **规则**
  - **指标**：接缝一致（100%）、页序与章序（100%）、重复率（≤0.5）、术语禁用词（0）、密度 ρ（2.5–8）、覆盖（100%）。
  - **报告**：`GET /series/stitch` 返回每项指标、失败页/讲、建议修复动作。
  - **修复矩阵**：接缝不一致 → 1 页；重复/术语漂移 → 1 页或 1 讲；切点错误 → 相邻 2 讲（`replanFrom(k)`）；讲纲整体错误 → 整系列（需用户确认）。
  - **幂等**：同一报告重复执行修复不产生新调用（命中页级缓存）。
  - **状态**：机检全过 → `stitched`；人工抽听通过 → `verified`；未过且不修 → 保持 `unstitched`，不影响播放。
- **AC-105** 篡改术语写法（把“定义域”写成“定义区间”）→ 报告标出该讲，修复只重生成含该词的页/讲，其余讲缓存命中。
- **AC-106** 重复率 0.7 的两讲 → 报告建议“重生成衔接页”；执行后重复率 ≤0.5，第 1 讲其余页不变。

### FR-18 系列播放（含 1.x 分屏播放器）

- **描述**：系列作为可连播的播放单元；单讲可从系列目录单独打开（仍带系列上下文）。播放器沿用 1.x 的“左原文 / 右幻灯片”分屏，不是纯音频播放页。
- **规则**
  - **布局**：左 55% / 右 45%，分隔条可拖动并把比例记忆到 2.0 `preference.json`；宽度 <1040px 时上下堆叠（上幻灯片、下原文）。
  - **版式**：沿用 1.x 舞台视觉（米色底、宋体标题、要点、引文、右下页码）；`cover` 大标题 + 副标题，`content_text` 标题 + 1–5 条要点 + 右侧配图占位，`quote` 居中大字 + 出处。
  - **原文窗格**：按 `source_pages` 用同源 pdf.js 渲染 PDF 视觉版式（不是文本流）；命中 `source_anchor` 的段落高亮并滚入视野；`unanchored` 时顶部提示“本页未定位到原句”；顶部 chip 显示“第 N 页”与「打开原始 PDF」。
  - **音频**：进入不自动播放；「开始听」启动；有 `audio_file` 播文件，无文件且 provider=browser 时用浏览器朗读；Qwen 失败不自动回退浏览器，提示“本页未配音”。每页一个音频，`ended` 自动翻页并播下一页；预加载下一页；切页先停当前；支持语速 0.8/1.0/1.2 与静音。
  - **键盘**：空格播放/暂停、←/→ 翻页、F 全屏、Esc 退出全屏/返回。
  - **连播**：讲末页播完 → 5 秒过渡卡（“第 2 讲 · 函数（中）：极限”）→ 自动进下一讲 cover；过渡可跳过（点击/空格）。
  - **系列进度**：`{seriesId, lecture, slide}`；显示“系列 24/42 页 · 第 2 讲 3/18 页”；关面板重开可续；书架「继续听」直接跳到该讲该页。
  - **系列目录**：抽屉列出 N 讲（标题、章、页数、已听页），可跳讲；跳讲不重置已完成进度。
  - **降级**：某讲 `failed`/未生成 → 连播跳过并提示，不阻塞其余讲；`unstitched` 系列仍连播，仅列表标注。
  - **N=1**：仍生成系列（单讲）；UI 隐藏系列目录与过渡卡，但数据与 N>1 同一模型。
- **AC-107** 2 讲系列从第 1 讲最后页播放，10 秒内进入第 2 讲 cover 并出声；无人工点击。
- **AC-108** 播放到第 2 讲第 3 页关闭面板，重开点“继续听”回到该讲该页，不自动播放。
- **AC-109** 第 2 讲 `failed` 时连播第 1 讲结束后提示“第 2 讲未就绪”，不崩溃、不循环。
- **AC-123** 播放到某页：左侧 PDF 切到 `source_pages` 对应页，命中 `source_anchor` 的段落高亮并滚入视野；把该页改成 `unanchored` 后显示“本页未定位到原句”且不崩溃；拖动分隔条后关闭重开，比例保持；空格/←/→/F/Esc 均生效。

### FR-19 系列练习与导出

- **描述**：练习按系列组卷，覆盖 1.x 的题库、组卷、判题、讲解、补题、复习与场次；导出默认按讲，可选整套合并，保留 1.x 的音频/配图/备注能力。

#### FR-19.1 练习与复习（P1）

- **范围**：系列全部章，或系列内某一讲的章；新题要求该章至少有一个 `ready`/`ready_degraded` 讲覆盖；已有题的章可直接复习。场次 5–20 题。
- **题库**：每章 4–6 题，单书上限 300；题型单选 60% / 多选 20% / 判断 20%；难度易 30% / 中 50% / 难 20%。
- **字段**：题干 ≤120 字；单选 4 项、判断 2 项、多选 2–4 个正确项；选项 ≤60 字；`point` ≤16 字；`source_quote` 10–200 字且为本章原文连续子串；`explanation` 初始为 `null`。
- **题库准备**：`POST /practice/bank {seriesId, chapters?, topup?}` 独立异步作业，状态同生成；按章缓存，键 = `sha256(bookId|章号|章标题|章字数|promptVersion|blueprintVersion)`；单章失败不影响其它章；整章失败可重试；作业可取消。
- **补题**：`topup=true` 时按模式补题；`new` 补到 `count`；`mixed` 补到 `count` 且旧题不足用新题；每轮每章 +5，最多 6 轮且单次新增 ≤30 题；补题前二次确认（轮数、预计新增、耗时、上限），取消不调模型。
- **开场与题库解耦**：`POST /practice/session` 只从已有题库组卷，不触发生成/补题；题库不足返回 `E_BANK_INSUFFICIENT`，UI 需先调用 `/practice/bank` 或显式补题。
- **去重**：题库层三重去重（题干精确、Jaccard ≥0.80、同考点 ≤2），作用域同书同章/同书；组卷层不去重。
- **组卷**：`new` 只取未答；`mixed` 到期 ≤40%、新题 >50%、其余旧题按未掌握→已掌握补；`review` 只取到期/错题；同考点 ≤2；章数 ≤题数时每章 ≥1；开场冻结 `plan`。
- **作答**：逐题提交、提交即定、不可改选/回退；可「不会，看答案」（`picked: []`）；可中途结束，正确率分母 = 已答数；同 qid 重复提交幂等。
- **判题**：宿主本地判定（单选/判断比 key，多选比集合且全对），不调模型；只返回 `{correct, answer, source_quote, source_anchor, explanation?}`，`explanation` 仅当已缓存时返回，判题不触发生成。
- **讲解（独立动作）**：`POST /practice/explain` 只在用户点「查看讲解」时调用（≤8s，150–300 字，覆盖正确项、错误项、原文依据）；成功写回题库，失败置 `failed`；同题再错复用；离线时给正确答案与原文，不阻断下一题。答错不自动生成讲解。
- **记录与复习**：每答一题 append 到 `sessions/<sessionId>.json`（含 `series_id`）并更新 `mastery.json`；断点续练从第一道未答题继续；结束写 `summary`；错题本 = `last=wrong` 或 `box=0`；Leitner 5 盒 1/3/7/21/60 天，答错回盒 0；入口显示“待复习 N”。
- **标记**：可标「这题有问题」→ `flagged`，不再组卷但保留历史。
- **书档**：`practice/` 有则随包走（题库 MUST、掌握度/场次 SHOULD），按 `qid`/`session_id` 并集；讲解缓存不入包。
- **隔离**：不写 `slides.json`/`series.json`，不改讲状态机；题库作业与生成作业互不阻塞。

#### FR-19.2 导出 PPT（P1）

- **范围**：按讲导出，或整套合并；只导出 `ready`/`ready_degraded`；生成中 `E_PPT_BUSY`，其它未就绪 `E_PPT_NOT_READY`，空 `E_PPT_EMPTY`。
- **页数**：与 `slides.length` 严格一致（6–30/讲），不增页、不合并；第 1 页必须是 `cover`。
- **版式**：`cover`/`content_text`/`quote` 三种；复用舞台视觉（米色底、宋体标题、要点、引文、页码），原生文本框/形状，不整页转图。
- **配图**：仅 `image_status="ready"` 且有 `image_file` 的页嵌入；无图正文占满整宽，不留空图位；`image_prompt` 不上页。
- **音频**：仅 `audio_file` 真实存在时嵌入；`.wav` 优先、兼容 `.mp3`；缺失页跳过并在计划接口报“X/Y 页含音频”；嵌入文件本体，进入该页自动播放，点喇叭可重播。
- **备注**：每页一条，文本 = `audio_script` 原文（逐字，不截断、不加前缀），封面/引文页同样写。
- **命名**：`<书名>-精讲-<讲标题去掉“第 N 讲 · ”>.pptx`；非法字符替换；`content-disposition` 同时给 ASCII fallback 与 `filename*=UTF-8''`。
- **上限**：单文件 ≤150MB、≤15s、内存峰值 ≤256MB；超限优先提示“不含音频/按讲导出”，不静默截断。
- **整套合并**：按讲序拼接；讲间插入过渡页（讲标题 + 接缝句，`layout=cover` 复用）；页序 = 讲序 + 页序；备注保留；批量导出按讲各一份。
- **只读**：不调 LLM/TTS/ComfyUI，不写 `slides.json`/`series.json`，不落临时 PPT；导出前后 `books/` 递归 size+mtime 不变。
- **AC-110** 2 讲系列先 `POST /practice/bank` 准备题库，再“练一练”，组卷覆盖 7 章；不受“最多 5 章”限制；场次记录带 `series_id`，关面板可续。
- **AC-111** 整套合并导出：页序 = 讲序 + 页序；过渡页含讲标题与接缝句；删除过渡页后与按讲导出的页数一致。
- **AC-119** 练习：先 `POST /practice/bank` 准备题库，再 `POST /practice/session` 开场；题库不足时 session 返回 `E_BANK_INSUFFICIENT` 且不调模型；判题不触发讲解，点「查看讲解」才调 `/practice/explain`；到期题优先、答错进错题本、连续答对升级盒子、题量不足经二次确认后补题、中途结束正确率分母为已答数、重开续练、标记题不再出现。
- **AC-121** 导出：含音频时页内可播、含配图时页内嵌图、备注逐字等于 `audio_script`、批量按讲各一份、缺资源给 warning 且导出成功、超 150MB 提示按讲导出。

### FR-20 安装、升级与数据根

- **描述**：2.0 与 1.x 共用 `~/.dsh/book-slides/`；2.0 用 `meta.json.schema=2` 标识，检测到旧 schema 时**自动备份旧根**再初始化。
- **规则**
  - **发布形态**：同包名 `dsh-book-slides`、同插件 id；安装即替换 1.x，不提供并存模式或第二包名；版本号按 §6.14 的预发布序列执行。
  - **数据根**：`~/.dsh/book-slides/`，与 1.x 同根；`DSH_BOOK_SLIDES_ROOT` 可覆盖。2.0 只解析/使用 `schema=2` 的数据；旧根只做整体备份移动。
  - **自动备份**：启动时若根目录非空且 `schema≠2`，把整个旧根**原子重命名**到同父目录的 `book-slides.backup-<YYYYMMDD-HHmmss>/`（重名追加 `-2`、`-3`）；校验备份存在且文件数/体积大于 0 后，在原路径重建 2.0 数据并写 `meta.json.schema=2`。备份失败则中止升级，原根保持不动，报 `E_UPGRADE_BACKUP_FAILED`。
  - **升级后**：2.0 进入空书架，显示一次性提示“旧数据已备份到 `<path>`；2.0 不迁移，请重新导入 PDF”。备份目录不自动删除、不进入书档，可由设置页查看/打开。
  - **无独立单讲**：每讲属系列；N=1 也建系列，UI 仅隐藏“下一讲”与过渡卡。
  - **卸载与回滚**：2.0 数据占用同一根；回滚 1.x 时删除/移走同根下的 2.0 数据，把自动备份重命名回 `book-slides/`。
  - **书档**：2.0 包格式见 FR-22；明确拒绝 1.x 包；书档能力必须在 2.0 内提供。
- **AC-112** 本机 `book-slides/` 含 1.x 数据时启动 2.0：生成 `book-slides.backup-<时间>/`，备份内文件完整且 mtime 保持；原路径重建的 2.0 数据写入 `schema=2`、书架为空；提示包含备份路径。
- **AC-113** 模拟备份失败（目录不可写）：升级中止，原根与文件不变，返回 `E_UPGRADE_BACKUP_FAILED`，不创建半截 2.0 数据；修复权限后重启可正常备份。全程 LLM/TTS 调用 0 次。
- **AC-114** N=1 生成后有 `series.json`（1 讲），播放器无“下一讲”；删除系列后该讲不可访问（无游离模块）。
- **AC-115** 安装后插件列表只有一个「精讲」；路由前缀不变；无 1.x 面板/入口残留；`package.json` 版本与发布版本一致。

### FR-21 书架、导入、分章与设置（P0）

- **描述**：保留 1.x 的输入与书籍体验：书架卡面、导入校验、目录/机械分章、章校准、设置与作业 UI；数据写入同根下的 2.0 数据。

#### FR-21.1 书架（P0）

- 卡片流展示封面、书名、作者（有则显示）、章数、页数、系列数、最近系列与「继续听」。
- 排序：最近打开优先；无系列的书排在后面；书架 >200 本时 200 条上限 + 提示，不做分页。
- 卡片右上「⋯」：重命名、删除（软删除到 `trash/<bookId>/`，7 天内可从设置页恢复；不自动清理）。
- 菜单关闭：再点「⋯」、点菜单外任意区域、按 `Esc` 都能关；关菜单不吞这次点击（点卡片本体收起并打开书，点别的卡片/按钮照常响应）；菜单开着挂全局监听、关掉即摘。
- 空态：一句引导 + 「导入 PDF」按钮 + 支持拖拽整块区域。

#### FR-21.2 导入与封面（P0）

- **只入库**：只接受 `.pdf`，单文件 ≤200MB（超出不上传）；校验顺序：可打开 → 未加密 → 至少 1 页可提取 ≥50 字符；错误码 `E_PDF_CORRUPT`/`E_PDF_ENCRYPTED`/`E_PDF_NO_TEXT`。
- **不自动分章**：`POST /import` 只写 `source.pdf`、`pages.json`、`book.json`（`title`/`author`/`sha256`/`pages`/`lastOpenedAt`），不写 `chapters.json`、不生成封面；分章由 FR-21.3 的独立动作完成。
- **封面独立**：`POST /cover {bookId}` 生成/重生成书封（书名 + 作者 + 章数 + 稳定渐变），失败退回首章标题占位；`GET /cover` 只读取。
- **去重与进度**：按 `sha256` 判重；已在书架则提示并跳转；上传显示字节进度，提取显示“正在读取第 N/M 页”。
- **成功反馈**：进入详情页并提示“生成章节目录”；无章节时 Part 选择区为空。

#### FR-21.3 分章构建（P0）

- **独立动作**：`POST /chapters/build {bookId, mode=auto|toc|mech, force?}`；可在导入后任意时刻执行/重跑，不依赖 Part、不启动生成。
- **主路径 `toc`**：用户指定目录页码范围 → 模型读成“标题 + 印刷页码” → 校准成物理页 → 校验后落盘；校验失败回退机械切章。
- **校准**：印刷页 → 物理页用目录样本拟合偏移；校准后逐章校验起止递增、不重叠、覆盖全文；失败给出具体章号。
- **回退 `mech`**：按固定页数/字数机械切分（附录 A 规则），结果不含“目录”章；无章节标题的散文集得到 1 章“全文”。
- **启发式 `auto`**：书签 → 标题 → 机械。
- 实际模式与来源写入 `book.json.chapter_source`；手工改过的章带 `manual: true`，重解析不覆盖。

#### FR-21.4 章校准（P0）

- 章列表显示标题、起止页、字数、来源徽标（书签/目录/机械/手动）。
- 空章节（提取后 <50 字符）置灰不可选，标「空白页」。
- 支持改起止页、合并相邻章、拆分一章、重命名、按目录页码整体校准；保存前校验起止递增、不重叠、覆盖全文。
- 提供「全选本书」；超过 Part 上限（48 章）时提示并只选入前 48 章。
- 校准只影响后续规划；已生成系列保留原章快照，不因校准被重写。

#### FR-21.5 设置与运维（P0）

- **语音**：供应商、TTS 模型、Key（password，已保存只显示末 4 位）、音色、语速、试听；Key 存 `voice.json`（0600），接口只回 `hasKey`/`apiKeyMask`。
- **模型**：只读展示“当前使用 DSH 默认模型”，不提供独立 Key。
- **配图**：策略、IP/端口、风格后缀、工作流导入/恢复默认/测试连接（P1，见 FR-24）。
- **导出默认**：是否含音频、配图、备注（默认全含；缺失时 warning 并继续）。
- **存储**：显示同根下的 2.0 数据路径、占用空间、回收站条目数与「清空回收站」；列出同父目录的 `book-slides.backup-*` 升级备份，可打开/删除；清空后 `trash/` 为空且占用下降。
- **诊断**：插件包版本、产品版本 `2.0`、`schema`、DSH 版本、pdfjs 版本、最近 5 条错误（只含错误码与长度，不含正文）。

#### FR-21.6 作业 UI（P0）

- 文本三阶段进度（structuring/validate/anchor），1s 轮询；显示当前讲/总讲数与页进度；生成后自动定位到“生成中”条目。
- 可取消（10 秒内停止，已写盘部分保留，状态 `cancelled`，可重跑并复用已完成阶段/音频缓存）。
- 失败显示错误码、可读原因与「重试」；重试复用已完成阶段；断网 90 秒内报 `E_LLM_TIMEOUT`，不留半截讲。

#### FR-21.7 偏好（P0）

### FR-22 书档导入/导出（P1）

- **描述**：把一本书的全部可再生状态导出为自包含 ZIP「书档」；在任意 2.0 数据目录导入后，书、章、系列、讲与音频保持可用，不需要重新生成。支持多本批量。
- **目标判据**：导入后同时满足「书在」（书架/章/原文可渲染）、「讲在」（系列/讲可播放）、「点开还能听」（有音频的页出声且是原音频，无音频页明确提示）。
- **容器**：`manifest.json` + `books/<bookId>/…`；单本 N=1，批量同一包内 N 项；不嵌套 ZIP。
- **内容**：只允许 MUST/SHOULD 白名单；`voice.json`（含 Key）、`audio-cache/`、`trash/`、`batches/`、`preference.json`、`progress.json`、`*.tmp` 不得入包；音频默认包含（播放 WAV 不需要 Key/网络）；`practice/` 有则随包走（题库 MUST、掌握度/场次 SHOULD）。
- **身份**：书用 `book.json.sha256`；系列/讲用 `contentKey = sha256(讲纲 + slides 去标识字段)`；`bookId`/`seriesId` 只是本地别名；去重/合并/幂等用稳定身份。
- **落位与冲突**：目标 `bookId` 空闲则沿用；被不同 `sha256` 占用则整本拒绝（`E_PKG_ID_CONFLICT`）；`policy ∈ merge（默认）/skip/copy`；`merge` 只补系列/讲，不改目标书/章/原文；按 `contentKey` 去重；章对不上的讲标 `orphan` 不导入；不提供覆盖式导入。
- **零生成**：导入全程不调 LLM/TTS、不重新解析 PDF；缺失项按状态归一，补齐由用户显式触发（重试/仅补配音/重新解析）。
- **原子性**：解压到 `.import/<id>/`，全部校验通过后整目录 rename 进 `books/`；失败清理；启动时清理 >24h 残留。
- **批量**：逐本判定，一本失败不影响同包其它本/其它包；响应 `{ok, items[], summary}`，HTTP 200。
- **状态归一**：非终态讲 → `interrupted`；`slides.json` 在但音频缺失 → `ready_degraded`，该页 `audio_file=null`、`audio_provider="none"`（不得清空字段导致回退浏览器朗读）；缺 `source.pdf` 整本拒绝。
- **排序/只读/上限**：导入书 `lastOpenedAt=导入时间`；导出不改 `books/`、不落临时 ZIP；单批 ≤10 本、单包 ≤4GiB，超限传输前拦截。
- **接口**：`GET /export`、`GET /export/size`、`POST /import/package`、`POST /revoice`。
- **AC-125** 导出单本再导入：书架/章/原文/系列/讲都在，音频页可播且与原音频一致；二次导入同包命中 `contentKey` 不重复；目标已有同 `bookId` 不同 `sha256` 时整本拒绝；批量中一本坏包不影响其它本；包内无 Key/缓存/回收站/临时文件。

### FR-23 语音（P0）

- **供应商**：`qwen3-tts` / `browser` / `off`，默认 `browser`（不静默产生云端费用）；Qwen 模型白名单 `qwen3-tts-flash`；音色只列 48 个非实时系统音色，传值必须与列表一致。
- **Key**：存 `voice.json.apiKey`（0600）；`GET /voice` 只回 `apiKeyMask`（如 `••••a1b2`）；输入框 password，空输入不覆盖旧 Key；日志/错误/URL 不含 Key。
- **试听**：`POST /voice/probe` 用当前 provider；Qwen 成功返回 `audio/wav`（不落盘/不缓存），失败返回 JSON 错误码；浏览器模式返回朗读参数。
- **独立触发**：配音不随文本生成自动执行；必须由用户显式调用 `POST /revoice`（或 UI「生成语音」）。文本 `ready` 不依赖 `voice_status`。
- **配音作业**：每页一次请求，文本为 `audio_script`（40–220 字）；并发 2、单页超时 60s、失败重试 1 次；写 `audio/NNN.wav` 并回填 `audio_file`/`audio_provider`；`audio_ms` 优先 WAV 头，否则按字数估。
- **状态**：`voice_status ∈ none|partial|ready`，独立于系列/讲 `status`。
- **失败与降级**：未配置 Key → `voice_status=none` + `E_TTS_UNCONFIGURED`；部分页失败 → 成功页保留，失败页 `audio_provider:"none"`，`voice_status=partial` + `E_TTS_FAIL`；**不自动回退浏览器**；播放器按 `audio_file` 播，缺文件时按 FR-18 的 provider 规则处理（browser 可用则朗读，否则提示未配音）。
- **缓存**：键 = `sha256(provider|model|voice|format|sample_rate|text)`，目录 `audio-cache/`；命中直接复制；401/403/429 不写缓存。
- **重新配音**：`POST /revoice` 对指定讲/系列重跑配音，复用缓存；只改音频字段，不改文字与 `slides.json` 的其他内容。
- **安全**：Key 只发 `maas.qianwenaiapi.com`；不写入 `slides.json`/`series.json`/日志；卸载不删 `voice.json`。
- **AC-126** 保存 Key 后重开只显示尾号，响应与 DOM 无完整 Key，`voice.json` 0600；文本生成 6 页不产生 WAV；调用 `POST /revoice` 后 `001–006.wav` 存在且可播；无 Key 时 `voice_status=none`/`E_TTS_UNCONFIGURED`；单页 500 该页 `audio_provider:"none"` 其余正常；同文本同音色二次配音命中缓存不请求 API；`revoice` 只改音频字段，不改文字。

└── books/<bookId>/

### 6.2 `parts.json`

{

  "parts": [
    { "id": "p3f9c2", "title": "函数",

### 6.6 不变式

| 编号 | 不变式 |
|---|---|
| I0 | 同书内任意两个 Part 的 `chapters` 交集为空 |
| I1 | 讲覆盖完备且不重叠：`∪lectures[].chapters = series.chapters` |
| I2 | 讲按章号升序；相邻讲章不重叠；章号连续时页区间相接；切点落在页内时允许相邻讲共享该页（至多重一页） |
| I3 | 每讲章数 ∈ [1,6]，页数 ∈ [6,30] |
| I4 | 每讲字数 ≤ 8 万（工程上限），超出必须再拆 |
| I5 | 相邻讲有且仅有一条 seam，`seam.from=i`、`seam.to=i+1` |
| I6 | 接缝句两处逐字复用（cover 开头 / 末页结尾） |
| I7 | cover 存在且为第 1 页（沿用 `validateSlideSet`） |
| I8 | `terms[].forbid` 在系列内出现次数为 0 |
| I9 | 每讲 ρ ∈ [2.5,8]（越界告警，不阻塞） |
| I10 | N=1 不产生 seam，但仍生成系列（单讲）；无独立模块路径 |

### 6.7 HTTP 接口（2.0）

前缀 `/dsh-book-slides/`，同源校验。错误响应统一为 `{ok:false, code, message, hint}`（**格式**沿用，语义不兼容）。

PDF 导入、书架、PDF 流沿用同名路由（`/import`、`/books`、`/book`、`/file`），数据用 2.0 schema；**不提供** `/module` 旧路由。2.0 起这些正式路径由 2.0 接管，1.x 同名处理器默认关闭（`DSH_BOOK_SLIDES_LEGACY_ROUTES=1` 仅用于排查）。

| 方法 | 路径 | 请求 | 响应 |
|---|---|---|---|
| GET | `/meta` | — | `{ok, version, product_version, schema, legacy, notice}`（§6.14） |
| GET | `/books` | — | `{ok, books:[{id,title,author,cover,pages,chapters,seriesCount,lastSeries,importedAt}]}`（FR-21.1） |
| GET | `/book?bookId=` | — | `{ok, book, chapters, parts, series}` |
| POST | `/import` | 裸 PDF + `x-file-name` | `{ok, bookId, book}`（只入库，不做分章/封面） |
| POST | `/chapters/build` | `{bookId, mode=auto\|toc\|mech, force?}` | `{ok, chapters[], mode, confidence, warnings[]}`（可重跑） |
| POST | `/cover` | `{bookId, force?}` | `{ok, cover}`（生成/重生成封面） |
| GET | `/file?bookId=` | — | `application/pdf`，支持 Range |
| GET | `/cover?bookId=` | — | 书封图片（PNG） |
| GET | `/chapters?bookId=` | — | `{ok, chapters:[{n,title,from,to,chars,source,manual}]}`（FR-21.3/21.4） |

### 6.8 状态机

```
系列：draft ─▶ planned ─▶ drafting ─▶ stitching ─▶ ready
                    │            │
                    │            ├─▶ partial
                    │            └─▶ failed / cancelled
                    └─▶ cancelled（未开始）
讲：  queued → structuring → validate → anchor → ready / ready_degraded / failed / cancelled
语音（独立于文本）：none → voicing → ready / partial / failed
```

- `draft`：`POST /series` 已建容器，尚无 plan；不可启动生成。
- `planned`：`POST /series/plan` 已写入 plan；可启动。
- 文本作业与配音作业分离：系列/讲 `voice_status` 独立记录，不阻塞文本 `ready`。

- 同一系列同一时间只允许一个作业；同一讲同一时间只允许一个生成作业。
- DSH 重启后：`drafting`/`stitching` → `interrupted`，可续跑（已完成讲跳过）。
- `partial`：至少一讲 `ready` 且至少一讲未就绪；允许播放与导出已完成讲。

### 6.9 幂等与缓存键

```
briefsKey   = sha256(bookId | chapters | prompt_version | model)
seriesKey   = sha256(bookId | part 快照 chapters | briefsKey | plan_version | model | prompt_version)
lectureKey  = sha256(seriesKey | lecture.chapters | pages | plan 切片摘要)
```

- `POST /series` 幂等键 = `sha256(bookId | partId | part_version | plan | title)`；同键返回已有 `seriesId`，不改变状态、不起作业。
- `POST /series/start` 命中 `seriesKey` 且状态为 `ready`/`partial` → 返回 `cached=true`，不重复调用模型。
- `part_version` 变化只影响新建系列；已建系列沿用快照，UI 标“基于旧快照”。
- 讲内批检查点沿用 `batches/`，重试只补未完成批。

### 6.11 长任务、取消、续跑与批量契约

**通用规则**

- 所有可能超过 2 秒的操作必须给出 `jobId` 或可中止的请求标识，并有 `status`：`queued/running/cancelled/failed/done`。
- 取消必须幂等；取消后返回 `E_CANCELLED`（或 `{ok:true,status:'cancelled'}`），不产生半截新数据；已落盘的旧数据保留。
- 取消生成不删除、不回滚 Part；Part 只由用户显式编辑/删除改变。
- 只有声明“可续跑/可重试”的操作才保留中间状态；其余取消即清理 staging。
- 超时由服务端兜底，UI 显示“已超时，可重试”；超时与取消都不得留下半截 Part/series/book。

| 操作 | 接口 | 进度 | 取消 | 续跑 / 重试 | 超时 |
|---|---|---|---|---|---|
| 导入解析 | `POST /import` | 上传字节 + 解析页 | 客户端 abort（连接断开即停），服务端清理 staging | 重新导入 | 120s |
| 分章构建 | `POST /chapters/build` | 阶段 + 已处理页 | 客户端 abort | 重新构建 | 120s |
| 封面生成 | `POST /cover` | — | 客户端 abort | 重新生成 | 30s |
| 讲纲预览/保存 | `POST /plan/preview`（草稿）或 `POST /series/plan`（写系列） | 阶段 + 已处理章数 | 客户端 abort | 重新预览/重算 | 120s |
| 系列文本生成 | `POST /series/start`（series 已 planned、Part 已确认）→ job；`GET /series/job` | 第 k/N 讲、页 | `POST /series/cancel` | `POST /series/resume`；`POST /series/retry` | 单讲 10min |
| 单讲文本生成 | `POST /series/lecture/generate` | 批/页 | `POST /series/cancel` | `POST /series/retry` | 10min |
| 书档导入 | `POST /import/package` → `{jobId}`；`GET /import/package/job` | 本/字节 | `POST /import/package/cancel` | 重试未完成本 | 30min |
| 批量导出 | `GET /export/pptx/batch` | 流式字节 + 页/讲计划 | 客户端 abort；服务端清理临时文件 | 重新导出 | 5min |
| 练习题库 | `POST /practice/bank` → `{jobId}`；`GET /practice/job` | 章/题 | `POST /practice/cancel` | 重试未完成章 | 5min |
| 配图生成 | `POST /image/regen` → `{jobId}`；`GET /image/status` | 页 | `POST /image/cancel` | 单页重试 | 10min |
| 重新配音 | `POST /revoice` → `{jobId}`；`GET /revoice/job` | 页 | `POST /revoice/cancel` | 重试页 | 10min |

**系列删除**

- `DELETE /series?seriesId=`：先取消运行中作业，再删除该系列目录；返回 `{ok, cancelledJob}`；不删书、不删 Part。
- 删除书（`DELETE /book`）先取消该书所有作业，再进回收站；取消失败则中止删除。

**练习断点**

- `GET /practice/session?seriesId=` 返回当前未完成场次（含已答题、`plan`、下一题）；`POST /practice/session` 有未完成场次时复用，不新建。
- `POST /practice/answer` 同 `qid` 幂等；`POST /practice/finish` 写 summary。

**回收站冲突**

- `POST /trash/restore`：若目标 `sha256` 已在书架，返回 `E_BOOK_EXISTS` 与已有 `bookId`；UI 只能「打开已有」或「取消」，不自动复制/覆盖。

### 6.14 版本与预发布跟踪

**目标**：明确四个独立维度——**产品版本 2.0**（产品线）、**插件包版本 2.0.0**（可安装 SemVer）、**文档版本 v1.0**（本 SRS）、**数据 schema 2**；正式发布前用可排序、可追溯的预发布包版本。

| 阶段 | 版本示例 | 准入 | 承诺 |
|---|---|---|---|
| Alpha | `2.0.0-alpha.1` | 功能未齐，可安装构建 | 不承诺数据/schema 兼容；可重置环境 |
| Beta | `2.0.0-beta.1` | P0/P1 功能齐，进入缺陷修复 | `schema=2` 冻结；只修 bug，不加功能 |
| RC | `2.0.0-rc.1` | 内容/接口冻结，发布门待跑 | 只修发布阻塞问题 |
| 正式 | `2.0.0` | AC-92 ~ AC-141 全绿 | 最终发布，无预发布后缀 |

**规则**

- `package.json.version` 必须是合法 SemVer：`2.0.0-alpha.N` / `beta.N` / `rc.N`；不得使用 `2.x.y-alpha` 这类占位符版本。
- `N` 从 1 开始只增不减、不复用；每次打 tag `v<version>`，tag 必须与 `package.json.version` 一致。
- Alpha 可按里程碑/可安装构建打；Beta 在 P0/P1 功能齐后打；RC 在内容与接口冻结后打。
- 预发布期间 `meta.json.schema=2` 固定；若 schema 变更，必须升 `schema` 并按 FR-20 自动备份，不得用包版本掩盖 schema 变化。
- `GET /meta` 必须返回 `{version, product_version, schema, ...}`：`version` 是插件包版本（如 `2.0.0-alpha.3`），`product_version` 固定 `2.0`，`schema=2`；设置页诊断同时显示包版本与 `schema`；`CHANGELOG` 按包版本记录。
- 2.0 未发布前不得出现 2.1；最终 `2.0.0` 不得带 `-alpha`、`-beta`、`-rc` 后缀。
- 预发布之间不承诺数据兼容；升级到正式版前必须保留备份。

- **AC-141** 版本一致性：`package.json.version`、git tag、`GET /meta.version` 三者相同；`GET /meta.product_version='2.0'`、`GET /meta.schema=2`；alpha/beta/rc 的 `N` 递增且不复用；最终 `2.0.0` 无预发布后缀；出现 `2.x.y-alpha` 或版本不一致时发布检查失败。

## 7 界面规格

**UI 基线**：2.0 必须沿用 1.x 的书架卡面、分屏播放器与设置分组；功能对等不等于可以用骨架 UI 替换。允许改版式细节，不允许把“卡片 + 封面 + 分屏 + 设置页”降级为纯文本或单栏。

### 7.1 详情页（章节选择）

- 章节列表有**两层状态**：**临时勾选**（尚未提交，底部汇总条）与**已确认 Part**（已落盘，组头 + 徽标）。两者不得混用。
- 已确认 Part 按组展示：标题、章数、字数、系列数、「已确认」徽标；组内章显示为选中态并标“属于《…》”，默认不可直接反选；编辑/删除走组头菜单。
- 用户勾选并点「确认此部分」后，界面必须立即用 `GET /parts` 的最新数据重渲染：Part 出现在列表顶部（或按章号就位），临时勾选清空，滚动到该组；**不得只保留临时勾选态**。
- 未确认 Part 时，可直接对草稿调用 `/plan/preview` 预览讲纲（不落 Part）；「开始生成讲义」仍需已确认 Part。
- 底部操作：勾选后显示「预览讲纲（草稿）」「确认此部分」；确认成功后，该 Part 组出现「预览讲纲」「开始生成讲义」「编辑」「删除」。
- 预览、生成、取消生成都不改变 Part；删除 Part 走独立操作。
- 刷新、重开面板、切换书再回来，已确认 Part 的组头与章归属保持一致。
- 勾选已属于其它 Part 的章：立即弹冲突框（并入/改选/取消），不先标红；取消不改变任何 Part。
- 编辑/删除 Part 成功后组头与章归属立即更新；删除只移除分组，不删系列。
- 创建失败（冲突/校验）不产生幽灵组，保留当前勾选以便重试。
- 底部汇总条从“已选 3 章 · 4.2 万字 · 预计 12 页”改为“已选 7 章 · 8.4 万字 · 将生成 2 讲 · 42 页 · 约 40 分钟”。
- “全选”不再按 5 章截断，改为按 48 章 / 8 讲上限截断并说明。

### 7.2 生成前预览

点击草稿或已确认 Part 的「预览讲纲」出预览层（**不写 Part、不写 series**；可取消；服务端中止模型调用）：

| 内容 | 说明 |
|---|---|
| 讲次表 | 第 1 讲：第 4–8 章 · 30 页；第 2 讲：第 9–10 章 · 12 页 |
| 总时长 | 页数 × 60 秒（±10%，页均约 1 分钟） |
| 计划来源 | `planSource=model/rule`；规则降级时显示“本系列未做衔接（unstitched）” |
| 接缝与术语 | 接缝句列表、术语表；缺失时说明原因 |
| 切点提示 | `cut_warn`（如“第 3/4 章可能属同一主题”） |
| 取消 | 取消即关闭预览，不改 Part、不写 series |
| 操作 | 「开始生成讲义」（需已确认 Part）/「调整切点」（拖动讲边界，只在章末）/「取消」；取消只关闭预览，不影响已确认 Part |

### 7.3 冲突对话框

标题：“第 5 章已属于《函数》”。三个按钮：

1. **并入《函数》**：本次选择并入该 Part，调用 `POST /part` 立即落盘（其 `version+1`，旧系列标“基于旧快照”），随后可预览/生成。
2. **改选**：回到列表，冲突章保持未选中。
3. **先移出**：跳转该 Part 编辑，调用 `/part/update` 移除冲突章后再回来。
取消 = 关闭对话框且未选三选：不改任何 Part、不调模型；生成不是这里的前置条件。三选一旦执行即落盘。

### 7.4 系列卡

模块列表上方新增系列卡：标题、`N 讲 · 总页数 · 约 X 分钟`、缝合状态徽标（已衔接 / 未衔接 / 部分就绪）、「继续听」「练一练」「导出」「⋯（重规划/删除）」。

- 「删除」需二次确认；运行中先取消作业再删，删除后列表立即移除。
- 「重规划」先展示受影响的讲（k..N）与预计重跑页数，确认后才调用。
- 「导出」进入导出对话框（按讲/整套/批量 ZIP），显示页数、音频/配图/体积 warning。
- `partial/failed/unstitched` 卡片显示下一步动作：续跑、重试失败讲、查看缝合报告。
- `draft/planned` 卡片：`draft` 显示「编辑讲纲」，`planned` 显示「开始生成讲义」；`drafting` 显示进度与取消。
- 音频独立：系列卡/讲菜单提供「生成语音」，调用 `/revoice`；文本 `ready` 不等待配音。
- 讲级操作：每讲可单独「生成本讲」「重试」；只影响该讲，不阻塞其他讲。

### 7.5 播放器

- 布局：左 55% 原文 / 右 45% 幻灯片，分隔条可拖并记忆；<1040px 上下堆叠。
- 原文：按 `source_pages` 渲染 PDF 视觉版式；`source_anchor` 段落高亮并滚入视野；`unanchored` 提示“本页未定位到原句”；顶部页码 chip + 「打开原始 PDF」。
- 顶部：`第 2 讲 · 3/18 页 · 系列 24/42`，右侧「系列目录」按钮。
- 讲末页播完 → 过渡卡 5 秒（可点跳过）→ 下一讲 cover。
- 系列目录抽屉：每讲显示标题、章、页数、进度；点击跳讲。
- 从系列目录打开某一讲：仍带系列上下文（进度、下一讲）；N=1 时隐藏“下一讲”与过渡卡。
- 底部：开始听/暂停、上一页/下一页、语速、静音、页码；键盘空格/←/→/F/Esc。

### 7.6 练习与导出入口

- 系列卡「练一练」：组卷范围 = 系列全部章；准备页显示“覆盖 2 讲 · 7 章”。
- 练习：先展示题库状态（已有题数/覆盖章），「准备题库」「开始练习」是两个独立动作；题库不足时开场提示先准备/补题，不自动生成；出题进度、补题二次确认、判题反馈、点击讲解后的 pending/失败、结束总结、续做与错题本按 §7.10 C9。
- 「导出」：默认“按讲导出（推荐）”；勾选“合并为一个文件”后展示页数 = Σ讲页数 + (N−1) 过渡页。
- 导出对话框显示音频/配图/备注开关、体积 warning、下载进度/失败重试；批量导出给 ZIP，按 §7.10 C11。

### 7.7 书架与书籍管理（P0）

- 书架为卡片网格：封面、书名、作者（有则显示）、`N 章 · M 页`、`K 个系列`、最近系列“继续听”。
- 排序：最近打开优先；无系列的书排在后面；>200 本时 200 条上限 + 提示。
- 封面由 `POST /cover` 独立生成；无封面时显示书名 + 首章标题占位，不阻塞导入/分章/生成。
- 卡片菜单：重命名、删除（进回收站）；书架顶部有「回收站」入口；菜单点外部/Esc 可关且不吞点击。
- 操作显示进行中/成功/失败；恢复遇同 `sha256` 显示 `E_BOOK_EXISTS` 与「打开已有/取消」。
- 回收站列出已删书，可恢复；恢复后卡片回到原位置，系列与进度保留；7 天内可恢复，不自动清理。

### 7.8 分章构建与校准（P0）

- 导入只入库；详情页无章节时显示「生成章节目录」，选择 `自动`（默认）/ `目录`（书签或印刷目录）/ `机械`（固定页数或字数）后才调用 `/chapters/build`。
- 目录模式先指定目录页码范围；解析后展示“标题 + 印刷页”，可校准为物理页。
- 构建后进入“章预览”：每行显示序号、标题、起止页、字数、来源徽标（书签/目录/机械/手动）；同时显示 `confidence` 与 `warnings`，目录解析回退机械时显式提示。
- 封面是独立动作：卡片无封面时显示占位，可点「生成封面」调用 `/cover`；不阻塞分章与生成。
- 支持改起止页、合并相邻章、拆分一章、重命名；保存前做覆盖与递增校验。
- 有目录页码时提供“按目录页码校准”按钮，显示校准前后差异；失败给出具体章号。

### 7.9 设置与作业（P0）

- 设置分四组：语音、模型（只读）、配图（P1）、存储与诊断。
- 语音：保存/试听/重配音显示进行中与结果；Key 只显示尾号，空输入不覆盖旧 Key。
- 存储：同根下的 2.0 数据路径、占用空间、回收站条目数、「清空回收站」；诊断：插件包版本、产品版本 `2.0`、`schema`、DSH/pdfjs 版本与最近 5 条错误（不含正文）。
- 导出默认：是否含音频/配图/备注；配图设置随 FR-24。
- 生成中系列卡显示“第 k/N 讲 · 第 p/P 页”，提供「取消」（停止可续跑 / 放弃并删除该系列；Part 保留）；取消后状态为 `cancelled` 或直接删除。
### 7.10 操作反馈契约（C1–C14）

所有操作统一要求：按钮进入 loading、禁用重复提交、错误可读、成功后刷新对应数据；取消与失败不得留下半截状态。

| # | 操作 | 必须出现 | 成功后 | 失败/取消 |
|---|---|---|---|---|
| C1 | 导入/分章/封面 | 导入进度；分章模式与 `warnings`；封面独立生成 | 打开详情/章预览 | 错误码 + 重试；staging 清理 |
| C2 | 讲纲预览 | 草稿或已确认 Part；加载/取消、讲次/页数/时长、seam、terms、`cut_warn`、`planSource`/降级提示 | 「开始生成讲义」可用（需 Part） | 可重试；不改 Part |

| C4 | 章校准 | 保存中/成功；受影响系列“基于旧快照”徽标与入口 | 列表刷新 | 校验失败定位到章号 |
| C5 | 后验缝 | 六项指标、失败讲/页、建议动作 | 修复后报告刷新 | 未修复项保留并标注 |
| C6 | 系列作业 | 第 k/N 讲、页进度、取消（停止可续跑 / 放弃并删除该系列） | 系列卡状态刷新 | 网络中断提示；可续跑；Part 不受影响 |

| C8 | 配图 | 逐页状态/整体进度、单页重试/取消 | 图状态刷新 | 失败页留白；不阻塞文字 |
| C9 | 练习 | 题库状态、出题进度、补题确认、判题反馈、讲解需点击「查看讲解」、结束总结 | 场次/错题本刷新 | 题库不足提示先准备，不自动生成 |
| C10 | 书档 | 导入/导出进度、冲突策略、逐本结果 | 书架刷新 | 单本失败不影响其它本 |

| C14 | 系列卡/讲 | `draft/planned` 的编辑讲纲/开始生成；`partial/failed/unstitched` 的下一步动作；讲级「生成本讲/重试」；删除/重规划确认与影响讲列表 | 列表刷新 | 删除取消运行中作业 |

| `E_REPLAN_RANGE` | `from` 越界 | 调整范围不合法 |

| `E_SERIES_UNPLANNED` | 系列尚无 plan 就启动 | 先生成/保存讲纲，再开始生成 |
| `E_BANK_INSUFFICIENT` | 题库不足就开场 | 先准备题库或补题 |
| `E_NO_SESSION` | 没有未完成练习场次 | 当前没有可继续的练习 |

## 12 交付计划（2.0）

### 12.1 估算口径

- **核心模型**：数据根与导入、分章/校准、Part/讲纲、逐讲生成/接缝、系列播放。
- **对等功能**：书架/书籍管理、设置/偏好、语音、书档、练习、配图、导出；并入 M1–M5，不单列版本。
- **合计**：25 人日 + 3 人日缓冲（1 人全职，约 6 周）；不含真书等待与模型调优。
- **不含**：v3 功能、跨书系列、移动端、云端同步、1.x 数据迁移。

### 12.2 里程碑

## 附录 B 核心算法（与 `series.js` 当前实现一致）

```
planLectures(chapters, pages, opts):
  N_est = max(1, ceil(totalChars / 60000))        # 仅作容量估计；实际讲数由装章决定
  for ch in chapters by n:
      if chars(ch) > 60000:
          flush(current)
          for seg in splitChapter(pages, ch, 60000):
              push lecture(ch=[ch.n], seg.from..seg.to, seg.chars)
      else:
          if current 已满（+ch > 60000 或章数 = 6）: flush()
          append ch to current
  if len(lectures) > 8: throw E_SERIES_TOO_MANY   # 不静默截断
  for L: L.pages = clamp(round(L.chars / 2000), 6, 30)
  warnings: cut_warn（mustNotSplit 被切开）/ cut_line（行切）/ density_warn（> 80000）
  assert I1..I4
  return {lectures, totalChars, totalPages, estMinutes, warnings, estimatedLectures}

splitChapter(pages, ch, limit):
  lines = 逐页逐行（带页码）
  blocks = 节标题开新块（第X节 / X.Y / 一、 / 【…】）
  pack blocks ≤ limit；单块超限 → 按行切；单行超限 → 按字切
  首段 cutKind=chapter；其余 = heading | line（line 记 cut_line）
  切点在页内时相邻两讲共享该页（至多重一页）

assertSeams(lectures, plan):
  for i in 1..N-1:
      seam = plan.seams[from=i, to=i+1]            # 缺失 → E_SEAM_MISSING
      sentence 非空且 ≤ 60 字                       # 否则 E_SEAM_LENGTH
      cover.audio_script.trim().startswith(sentence)  # 否则 E_SEAM_COVER
      last.audio_script.trim().endswith(sentence)     # 否则 E_SEAM_LAST
      两处朗读稿 ≤ 220 字                            # 否则 E_SEAM_AUDIO_LENGTH
  return {ok, checked, failures[]}

replanFrom(k):                                      # 规范已定，本期未实现
  保留 lectures[1..k-1]；重算 k..N 的装章、页预算与 seams；只失效 k..N 的缓存
```
