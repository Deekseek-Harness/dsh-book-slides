# 角色设定
你是一个资深的 AI 全栈开发架构师和产品经理。请帮我开发一个名为 “AI 书籍精讲插件” (Book-to-PPT Reader) 的 Web 应用插件。该插件的核心目标是将静态的 PDF 书籍重构为“幻灯片展示 + 语音讲解 + 原文对照”的沉浸式多模态阅读体验。

# 核心前提（非常重要）
**默认所有上传的 PDF 均为已经过 OCR 处理的纯文本型 PDF（包含完好的 Text Layer）。系统无需处理任何扫描件、图片或复杂的版面分析。**

# 核心业务流程
1. 用户在书架上传 PDF 书籍。
2. 系统直接提取 PDF 的文本层，通过简单的正则匹配提取出**基础的章节（Chapter）列表**。
3. 用户在界面上**自由多选章节**（例如勾选第1、2、3章），组合成一个自定义的“精讲模块”。
4. 用户点击“生成精讲”。系统直接截取选中章节合并后的干净文本，发送给 LLM 生成幻灯片数据（文字、要点、视觉提示词）及配音逐字稿，并转化为音频。
5. 进入分屏播放模式：一侧展示 PDF 原文，另一侧以 PPT 形式播放图文及音频。

# 功能需求详细说明

## 1. 书架与书籍管理 (Bookshelf)
- 支持本地纯文本 PDF 文件拖拽/点击上传。
- 书架以卡片流形式展示书籍封面（提取PDF首页渲染为封面图）、书名。
- 点击书籍进入详情页。

## 2. 目录解析与章节多选 (TOC & Multi-Select)
- **解析引擎**：使用 `pdf.js` 提取文本，或直接在后端使用简单的文本提取库。
- **正则匹配**：通过简单的正则表达式（如 `/(第[一二三四五六七八九十百千万\d]+章|Chapter \d+)/g`）提取出章节标题和对应的页码位置。
- **交互UI**：
  - 侧边栏展示章节列表，每个章节前带有一个 Checkbox。
  - 用户勾选多个章节后，点击“生成精讲”按钮。

## 3. AI 内容重构与生成 (AI Generation)
后端将选中章节的纯文本直接发给 LLM：
- **LLM 处理**：要求生成严格的 JSON 格式数据，禁止编造，只提炼原文内容。
- **TTS 语音合成**：将 JSON 中的 `audio_script` 字段文本逐页调用 TTS API。
- **JSON 数据结构要求**（前端需按此结构渲染）：
```json
{
  "module_title": "精讲：第1章至第3章",
  "slides": [
    {
      "page_index": 1,
      "title": "电影导演：不止是“咔嚓”一声",
      "layout": "cover", // cover(封面), content_text(图文), quote(金句)
      "bullet_points": ["揭秘电影幕后", "探索导演的艺术与责任"],
      "image_prompt": "手绘风格的红色胶卷指向一台电影摄影机",
      "audio_script": "大家好，今天我们来讲第一部分...",
      "source_text": "这里填入原文中对应此页PPT的原句或段落，用于前端字符串匹配定位。"
    }
  ]
}
