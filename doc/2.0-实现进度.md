## 5. 数据根、升级与回滚

- 数据根：`~/.dsh/book-slides/`（`DSH_BOOK_SLIDES_ROOT` 可覆盖），与 1.x 同根。
- 升级：启动时若根非空且 `schema≠2`，整根原子重命名到同父目录 `book-slides.backup-<YYYYMMDD-HHmmss>/`，校验备份非空后在原路径重建 2.0 数据；备份失败中止并报 `E_UPGRADE_BACKUP_FAILED`。
- 不迁移：2.0 不解析 1.x 数据，升级后进入空书架，需重新导入 PDF。
- 回滚：移走同根下的 2.0 数据，把 `book-slides.backup-<时间>/` 重命名回 `book-slides/`。
- 设置页可查看/打开/删除升级备份；`trash/` 保留 7 天，不自动清理。

## 6. 验证方式

```powershell
cd dsh-book-slides
npm install
npm run test:v2     # 21 个文件 / 117 项，0 失败
```

覆盖：数据根与升级备份、导入/分章/章校准、Part/briefs/讲纲、逐讲生成/预缝/后验缝、作业取消与续跑、播放器（PDF 高亮/键盘/连播/目录/进度）、设置/偏好/备份/诊断、语音与独立配音、**ComfyUI Qwen3-TTS 配音/工作流/音色表/串行队列**、系列删除、书档往返/冲突/批量与状态归一、练习题库/组卷/判题/讲解/Leitner/续做、ComfyUI 配图、按讲/整套/批量导出 PPT、长任务取消、回收站恢复冲突、路由唯一注册。

**手工走查建议（alpha.5）**：

1. 导入一本带文字层的 PDF → 生成章节目录（auto/toc/mech 各试一次）→ 校准并保存。
2. 勾 7 章 → 确认此部分 → 预览讲纲（草稿与已确认 Part 各一次）→ 保存为系列 → 开始生成。
3. 生成中看“第 k/N 讲 · 第 p/P 页”，取消 → 续跑；单讲重试；打开“缝合报告”并一键修复。
4. 系列卡「继续听」进分屏播放器：翻页看左侧 PDF 页与高亮、空格/←/→/F/Esc、拖动分隔条后重开、连播过渡卡、系列目录跳讲、进度条。
5. 设置页：语音试听、保存 Key 只看尾号、清空回收站、升级备份打开/删除、诊断五项。
6. 系列卡「生成配音 / 补配音 / 重新配音」→ 看进度/取消；长按 3s 看进度条与倒计时→ 确认弹窗；有音频后播放器直接播 WAV；删除系列后书与 Part 仍在。
6.1 设置 → 语音切「本地 ComfyUI（Qwen3-TTS）」→ 地址（默认 127.0.0.1:8188）→ 连接测试（版本/节点/模型音色）→ 试听测试；导入/恢复工作流与音色表；换 Serena 再试听，确认 `comfy-tts-workflow.json` 不变；系列卡生成配音，看 ComfyUI 排队/进度/取消；单页失败显示具体 `E_TTS_*`。
7. 系列卡「练一练」→ 准备题库（看逐章进度/取消）→ 开始练习 → 判题/查看讲解/标记/结束总结 → 关面板再「继续上次练习」。
8. 设置 → 配图切「本地 ComfyUI」→ 测试连接/测试生图 → 系列卡「生成配图/补配图/重新配图」→ 播放器看到真图；单页「换一张」只换该页，长按 3s 清空重出。
9. 系列卡「导出」→ 看计划页数/音频/配图/体积 → 下载按讲 PPTX；整套合并看过渡页；批量导出 ZIP。
10. 书架「⋯ → 导出书档」→ 删除书 → 回收站清空后 → 「导入书档」→ 书/系列/讲/音频/练习都在；重复导入不重复建系列。
11. v1.1 细节：播放器底部缩略图点页（旧音频停、原文同步）、配图提示词面板点外部/`Esc` 收起、配音失败后系列卡错误码与播放器顶部提示、确认弹窗居中且 `Esc`/点遮罩可取消。
