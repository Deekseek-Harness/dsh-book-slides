# 目录抽取提示词 v1

> 版本号 `toc-extract-v1`，写进缓存键。**改一个字就要改版本号**，否则老书会命中旧缓存。
> 这个文件是「模型该看到什么」的唯一真源；代码只负责拼装，不再内联提示词。

## 角色

你在做一件事：把一本书的**目录页原文**读成结构化的章节表。你不负责猜这本书排版如何，也不负责判断页码对应 PDF 的哪一页——那一步由程序用页眉页码和标题锚定完成，你只管**如实读出目录写了什么**。

## 输入

- `【书名】`
- `【总页数】` 这本书一共多少页（PDF 页数，不一定等于印刷页码）
- `【目录原文】` 目录页的逐行文本，每行前面带 `L12:` 这样的行号

目录原文可能是双栏、可能带引导点（`……`）、可能有 OCR 错字，这些都不归你修；你只需要按下面规则抽条目。

## 输出

只输出一个 JSON 对象，不要 Markdown 围栏、不要解释、不要前后缀：

```json
{
  "entries": [
    { "title": "第1章 计算机概念和技术", "printed_page": 1, "level": "chapter", "fixed_char": false },
    { "title": "附录C 控制器的硬件实现", "printed_page": 537, "level": "appendix", "fixed_char": true }
  ]
}
```

字段：

| 字段 | 说明 |
|---|---|
| `title` | 章节标题，照抄目录原文；**不要**加「第X章」以外的修饰，不要翻译 |
| `printed_page` | 该条目右侧最近的页码，整数；没有页码就整条丢掉 |
| `level` | `chapter` / `part` / `appendix` / `front` 之一 |
| `fixed_char` | 你在页码上做过 OCR 纠正时为 `true`，否则 `false` |

## 硬规则

1. **只收大章节。** `第X章`、`第X部分`、`Chapter N`、`Part N`、`序章/序言/前言/楔子/尾声/后记/附录X`。
   `1.1`、`6.9`、`习题`、`图 6-53`、`(6.10节)` 这类**一律不收**。
2. **页码只许来自原文。** 不许推算、不许按顺序补齐、不许猜。
   允许的纠正只有字符混淆：`O/o→0`、`I/l→1`、`S→5`、`Z→2`、`B→8`；改过就置 `fixed_char: true`。
3. **标题照抄。** 不改写、不补全、不删除副词（「浅谈」「简论」都留着）。
4. **去重。** 目录可能排了两遍（简目 + 详目），同号同名的只保留第一次出现的那条。
5. **排序。** 按 `printed_page` 升序；页码相同或缺失时保持原文出现顺序。
6. **宁缺毋滥。** 拿不准是不是一章的（比如只有一行「目录」），不要输出。
7. 章节数多于 60 条时，说明你把小节也算进来了，回头只保留最外层。

## 示例

输入（节选）：

```
【书名】计算机组成与设计
【总页数】608
【目录原文】
L1: 第2章 计算机指令
L2: 2.1～2.11
L3: 第3章 计算机的算术运算
L4: 3.1～3.9
L5: 附录C 控制器的硬件实现 C.1～C.6
```

输出：

```json
{"entries":[{"title":"第2章 计算机指令","printed_page":27,"level":"chapter","fixed_char":false},{"title":"第3章 计算机的算术运算","printed_page":99,"level":"chapter","fixed_char":false},{"title":"附录C 控制器的硬件实现","printed_page":537,"level":"appendix","fixed_char":false}]}
```

注意：`2.1～2.11` 这类小节行要跳过；`附录C` 带字母，属于 `appendix` 层。

## 你不需要做的事

- 不要判断印刷页码与 PDF 页的偏移
- 不要输出页码范围（只要起点）
- 不要给每章写摘要
- 不要在 JSON 前后加任何一句话
