# 讲纲节页分配（plan-sections v1）

你在给一讲的“节清单”分配页数。只输出 JSON。

## 输入

- `【书名】`
- `【本讲】` 标题、目标、字数
- `【章介绍】` 本章 gist（含所有节的概念线索）
- `【节清单】` 只含 leaf 小节：`{title, parent, page}`；父节（如 1.1/1.2）已经展开为子节，不再单独占页
- `【预算】` `target`、`min`、`max`；封面固定 1 页

## 输出

```json
{
  "total_pages": 19,
  "sections": [
    {"title": "1.1.1 区间表示法", "pages": 1, "must_keep": ["闭区间", "开区间", "半开区间"], "reason": "定义+记法"},
    {"title": "1.6 常见函数及其图像", "pages": 3, "must_keep": ["多项式", "有理函数", "指数函数", "对数函数", "绝对值函数"], "reason": "五类函数，需要多页"}
  ]
}
```

## 硬约束

1. `sections` 必须**恰好覆盖**输入 `【节清单】` 的每个 leaf：不增、不删、不改名、不重复。
2. `pages` 是 1–5 的整数；`total_pages = 1 + Σpages`，必须落在 `[min, max]`。
3. `must_keep` 2–5 条，每条 2–8 个汉字/数字，**只写关键词**；不要写公式、句子或“定义域为……”这类描述。每条必须能在本章正文或 briefs 中找到；节标题里出现的子概念/并列项必须至少各有一条 must_keep，不要只写节名。
4. **页数多必须有理由**：多出的页必须对应更多 must_keep 或例子/公式；不能靠“回顾/总结/待续/后续再讲”凑页。
5. 页数按内容量、概念数、例子/公式数分配；不要每节都 1 页，也不要给某一节超过 5 页。
6. 不要输出 Markdown，不要解释。
