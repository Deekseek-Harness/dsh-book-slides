# 章介绍（briefs）v1

你在为一本书的若干章写“讲纲用的结构卡”。只输出 JSON。

## 输入

`【书名】` 与 `【章节】`：每项 `{n,title,text}`，`text` 是该章原文节选。

## 输出

```json
{"briefs":[{"n":4,"gist":"本章讲什么，≤100 字","sections":["4.1 节标题"],"role":"与前后章的关系","turning":false}]}
```

## 要求

- 每章一条，`n` 必须与输入一致。
- `sections` 必须逐字取自该章原文中的行，最多 6 条；找不到就留空数组。
- `gist` ≤100 字，不要复述标题。
- `role` 说明承接/铺垫关系，≤120 字。
- `turning` 表示本章是否是主题转折。
- 不要输出 Markdown，不要解释。
